## 定义

- **数据源**：通达信概念现价成交额（活跃度）+ 概念成分实时行情（`sectors/tdx.py`）。通达信 HQ / 东财现价失败时：概念活跃度走板块轮动缓存，成分现价走新浪；本地 `tdx_members_index.json` 有概念成分则复用，禁止因 HQ 超时把池写成 0 票。
- **偏高概念**：截面成交额 **≥ 中位数**，最多扫成交额 **Top40**（剔风格/宽基后凑满约 30 只）
- **概念内龙头**：过滤后按涨跌幅、成交额取前 **2**（每概念至多 2 只）
- **池规模**：去重后约 **30** 只（不够则继续加概念，满 30 停）
- **过滤**：非创业板、非科创板、非北交所、非 ST、现价 **< 100**
- **周期**：滚动 **近 3 个月**（选股日往前 3 个月～当日；名单用到选股日后 3 个月，非自然季度 Q1/Q2/Q3）；产物 `backtest/strategy16_core_leader/picks_quarter.json`
- **盘前 / 行情空**：概念成交额/个股涨跌幅可能为空，则回退最近一轮板块缓存；开盘后请重跑 CLI 按涨跌幅取龙头。`save_picks`：**本次 0 票不覆盖**已有非空池。

## 选股逻辑（流水线）

1. 拉概念活跃度（通达信报价 → 东财 → 轮动缓存 → 指数 K）。
2. 剔风格/宽基概念（基金重仓、沪深300 等）。
3. 成交额 ≥ 截面中位数，再取 Top40。
4. 按活跃度从高到低扫概念：成分过滤后按 **涨跌幅 ↓、成交额 ↓** 取至多 2 只。
5. 跨概念去重，凑满约 30 只即停；名单滚动近 3 个月冻结。
