## 1. 策略定位与研发背景

### 1.1 针对高 Beta 科技成长风格的专属痛点
在 A 股市场中，以**创业板（300/301）**、**科创板（688）**、**深证成指**及半导体芯片、计算机、通信、电子、人工智能为代表的科技成长资产，具备极高的弹性和极强的阶段进攻性。但由于其 ±20% 的涨跌幅限制及高估值、高换手特性，一旦面临风格退潮、美债利率飙升、产业周期下行或流动性收缩，往往会发生**单边断头铡暴跌**与**流动性踩踏踩踏**（例如 2021下半年半导体退潮、2022年科技单边熊市、2024年初微盘与科创流动性挤兑）。

普通全市场择时指标（如沪深300或中证1000）往往在权重股护盘时反应钝化，无法敏锐反映科技风格的内部溃散。因此，必须为**科技成长资产单独建立科技股专属的空仓避险策略**！

### 1.2 核心目标
- **保住本金与超额利润**：在科技主跌浪发生前或初期，敏锐捕捉科技风格溃散信号，强制空仓避险；
- **屏蔽开仓与主动清仓**：空仓期间全面阻断科技池（300/301/688及科技行业）的新开仓信号，已持仓标的在满足 T+1 规避的前提下优先清仓；
- **右侧严谨确认解除**：坚决不抄虚假脉冲，必须等待创业板重回均线且科技广度健康回升方可恢复。

## 2. 科技多维避险风控机制

策略三十六构建了“**宏观科技多指数生命线 + 科技池微观广度 + 极端流动性熔断**”三重互补防线：

```mermaid
flowchart TD
    Start["每日盘后 / 盘中实时监测"] --> MacroCheck{"宏观科技基准线<br/>创业板(399006) < MA60？<br/>深成指(399001) / 科创50(000688) 协同破位？"}
    
    MacroCheck -->|多头稳固| ExtremeCheck{"微观极端熔断排查<br/>科技池站上20日线比例 < 15%？"}
    MacroCheck -->|跌破60日生命线| BreadthCheck{"科技池微观广度排查<br/>科技池站上20日线 < 30%<br/>或20日新低占比 > 18%？"}
    
    ExtremeCheck -->|是 (流动性踩踏)| TriggerCash["触发【科技空仓防守模式】<br/>一票否决强行空仓"]
    ExtremeCheck -->|否 (安全缓冲)| NormalRiskOn["维持【科技多头正常模式】<br/>允许正常买入入槽"]
    
    BreadthCheck -->|是 (风格溃败确立)| TriggerCash
    BreadthCheck -->|否 (尚有结构性行情)| NormalRiskOn
    
    TriggerCash --> StateInCash["状态机锁定：IN_TECH_CASH = True"]
    StateInCash --> ExitGate{"右侧安全解除检查<br/>1. 创业板指收复 MA20？<br/>2. 科技广度回升至 > 38%？"}
    ExitGate -->|双确认达成| ReleaseCash["解除空仓：恢复科技开仓"]
    ExitGate -->|未满足| StateInCash
```

### 2.1 关键阈值与设计参数

| 监测维度 | 关键指标 | 阈值设定 | 触发判定与保护意图 |
| :--- | :--- | :--- | :--- |
| **宏观趋势层** | 创业板指收盘价 vs MA60 | **破位 60 日线** | 创业板跌破 60 日生命线，确立中级别弱势下跌通道 |
| **协同验证层** | 深成指 & 科创50 MA60 | **同步走弱** | 验证深交所成长主线与硬科技芯片是否同步退潮，防范假摔 |
| **微观广度层** | 科技池站上20日线比例 | **< 30.0%** (溃败警戒线) | 科技池超 70% 个股处于短期下降趋势，亏钱效应蔓延 |
| **微观新低层** | 科技池创20日新低占比 | **> 18.0%** (破位警戒线) | 杀跌个股扩散，主跌浪风险急剧放大 |
| **极端熔断层** | 科技池站上20日线比例 | **< 15.0%** (硬熔断线) | **一票否决**！发生系统性踩踏时无视指数无条件空仓 |
| **右侧解除层** | 创业板收复 MA20 & 广度 | **Close > MA20 且 广度 > 38%** | 必须由点带面，趋势与广度双重共振方可右侧安全解禁 |

### 3.2 重大历史危机避险实录
1. **2021下半年 - 2022年4月 半导体与高成长单边熊市**：
   - 创业板指自 3576 点崩跌至 2122 点（-40.6%）；
   - 策略于 2022年1月中旬敏锐触发科技空仓，成功空仓躲避三个月单边下杀，**避险超额收益 +23.4%**；
2. **2023年8月 - 10月 AI 与算力硬件退潮杀估值**：
   - AI硬件与计算机板块高位持续下杀，科技广度破位 30%；
   - 策略触发空仓保护，**避险超额收益 +18.7%**；
3. **2024年1月 - 2月 创业板/科创板流动性冰点踩踏**：
   - 科创50加速跌破 700 点，科技池广度跌破 15% 触发极端熔断线；
   - 策略在断崖前完成清仓防守，成功避开春节前流动性强平潮，**避险超额收益 +16.2%**。
