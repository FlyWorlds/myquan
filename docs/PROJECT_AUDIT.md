### P0 · 已修复（2026-09-11，仍成立）

- 三槽 1m：半仓后 `sold_today` 不再禁剩余仓当日止盈。
- 单票 1m 模拟：半仓减股并跨日保留 `tp_stage`。

### P1 · 盯盘：10%「半仓」实际全清（2026-09-13 已修）

规则写「浮盈 ≥10% 卖一半」。现已对齐三槽 1m：

1. `path_dependent_pullback_hit` 传入真实 `shares` / `tp_stage`。
2. `apply_stop_fill` 对 `ladder_half_10` 只卖 `lot_half_shares`，信号写「半仓止盈」。
3. 持仓落 `tp_stage=1`、`last_tp_ts=触达分钟`；下一轮从该分钟**之后**继续。
4. `realized_today` 带 `after_qty` / `full_exit`：半仓后允许当日再卖剩余；当日仍禁再买该票。

不接券商：本地只记信号与纸面数量，人工按「半仓止盈」下单。

### P1 · `run_strategy16()` 不是因子26

`run_factor26_strategy` 在 `stop_anchor=open` 时改成 `day_high`，然后走 `run_open_break`。单票 CLI 收益不能当成策略十六生产表现。

### P1 · T1「已记」依赖盯盘在收盘仍在跑

买入日 `t1_trail` 只在 `is_close_confirmed()` 后落库。进程若在 14:57 前挂掉，次日 `overnight_armed` 可能为假，只剩硬保护 2.5%，**不会**走峰值回落 2.5%。实盘级要求：日末落库与开盘回放不能依赖「进程碰巧活着」。

### P1 · 无券商通道 / 无成交回报

盯盘把触发价视为必成，本地改 `qty`。没有：报单状态机、部成、废单、持仓与券商对账、前复权研究价 vs 未复权盘面在除权附近的 0.01 档。**不能把本地「已平仓」当成已成交。**

### P2 · 同一根 1m：用当根 high 切档、用切档前 peak 算卖价

`eval_multi_tp_bar`：`live_ok` / `peak_gain` 含本分钟最高；`mid_gain_first_hit` 的 peak 仍是 `peak_before`。1 分钟内高低次序不可观测。同根若先冲过 10% 再砸穿硬保护，代码先走硬保护（未进 10% 半仓）。对实盘限价单来说，10% 卖单可能先成交——这是 1m OHLC 的固有近似。

### P2 · 因子27 宇宙不是 PIT 成分

池按通达信**现价**概念成交额 + **当前**成分涨跌幅在 `as_of` 打一次，再冻结约 3 个月。概念成分与活跃度都不是历史时点截面。另并**公共自选池**（天通/凯盛/东材/金安）是人工宇宙，不是因子信号。

### P2 · 生产对账窗只有约 7 个交易日

开盘阈值 `{2, 2.5, 3}%` 用 2026 至今日线夏普择优（`--fit-thr`），再在近 7 日 1m 上看组合。**无显著净边际的统计结论**，只能当执行核对。未算 CSCV/PBO/DSR。

### P2 · 仍成立的执行假设

- 盯盘触发价必成，无盘口/排队/一字反复开板（跌停封单已单独处理）。
- 日线失败盯盘吞异常 → 前日过滤不通过，买点被静默抑制。
- 现价 `last≤工作卖价` 仍可把展示打成「已触止损」（结算仍要 1m 路径 + 连续竞价）。工作线修好后，这条旁路不再用 15% 目标价误报，但仍不是路径成交。

## 5. 算法是否合理（实盘视角）

**合理处**

- 买用开盘阈值、不用当日最低派生攻击波（默认关），避免一字开板后再「将买入」。
- 卖按 1m 顺序，禁止全日 low 撞抬高后卖价。
- T+1、跌停封单、低开破硬保护按开盘卖，符合 A 股可执行约束。
- 中赚用点时点 20 日波动（盯盘 `_vol20_daily_for` 不含当日），没有用未来波动。
- 三槽、当日禁再买，限制换手和叠仓。

**不合理 / 不够实盘**

- （已修）10% 半仓曾在盯盘退化成全清；现信号「半仓止盈」、纸面减半。
- 阈值按 2026 短窗夏普择优，再在近 7 日 1m 上看结果：这是执行核对，不是策略期望。
- 因子27 用**当日涨跌幅**在活跃概念里取龙头，再冻 3 个月：选股日有明显的「今天谁涨就选谁」，之后三个月吃的是冻结名单，不是可滚动的截面因子。
- 公共自选池与因子池混在同一交易宇宙，信号来源不纯。
- 本地盈亏不含盯盘滑点/佣金；`pool_1m` 本次才扣费。两边仍不能对券商交割单。

## 7. 距「可实盘级」还差什么

1. **券商**：报单、部成、持仓对账、手工录入入库（`TODO.MD` P0）。
2. **盯盘半仓状态机**（已修）：`tp_stage` + `last_tp_ts` + 当日第二笔卖出。
3. **T1 已记持久化**：不依赖收盘进程仍活着（日终任务或开盘用昨日 K 重算）。
4. **长窗独立 1m 验证**：冻结阈值与池之后，再跑样本外；短窗数字只作核对。
5. **因子27 PIT**：历史时点概念活跃度之前，不要把池回测当选股溢价。
6. **信号单一真源**：只认盯盘 1m + `eval_multi_tp_bar`；Decision / `run_strategy16` 标成研究旁路。
