## 结论

本轮代码及定向测试已完成复查，发现的问题已修复；不等于已经完成新进程真实行情验收。代码位于实际项目工作区，未提交、未推送，未替换正在运行的Python，未改写今天的成交。

仍不能证明新方案实际收益更好：没有完整历史报价事件流。下面的分钟收盘价代理仅用于揭示漏采样风险，不能作为秒级实盘回放，也不能判断免费行情已无延迟。

## 复审修复

| 风险 | 修复与验证 |
| --- | --- |
| 日线准备/分钟回放拖住买卖和首屏 | 实时快照只读缓存报价与数据库；参考数据后台准备，实时分钟入口误用拒绝 |
| 旧扫描与新事件链重复买卖 | 策略16走报价入口，旧collect分支不执行；重复订单/重复半仓测试 |
| 卖出提交后继续修改旧嵌套对象 | 数据库响应替换状态后重新获取订单和持仓；先卖再买的订单状态落库测试 |
| 手工锁仓/一字跌停/可卖量约束遗漏 | 报价卖出及开盘保护均补齐；半仓按可卖数量计算 |
| 当日买入的收盘已记状态丢失 | 使用原有T+1已记函数维护；重启首次报价可依据正式昨收恢复，标注来源，不反造昨天最低价 |
| 新买入继承上一轮报价低点/水位 | 新建仓清理报价周期状态；行情早于持仓峰值时拒绝 |
| 已准备订单的日线依据被替换 | 挂单保存日线指纹，成交前只读比对，变化则等待重新准备 |
| 接近涨停的旧挂单绕过禁买 | 准备及触发两层过滤；新审核可阻断同ID旧挂单 |
| 迟到源时间被写成实际成交时间 | 分开行情源、接收、真实决策和成交时间；禁止倒填 |

## 历史退出对照

数据：冻结参考池对应的10月8、9、12、13日分钟数据，固定原参考回测的8笔入场时间/价格/数量，共458,464元累计买入成本。每笔独立比较退出；不重新分配现金或槽位，累计成本包含资金重复使用。

| 指标 | 分钟OHLC退出参考 | 分钟收盘价输入报价引擎（代理） |
| --- | ---: | ---: |
| 固定入场笔数 | 8 | 8 |
| 毛盈亏合计，含期末未平仓盯市 | -10,336.00元 | -11,926.00元 |
| 扣原回测费用/滑点后盈亏合计 | -11,371.66元 | -12,870.34元 |
| 期末未平仓笔数 | 2 | 3 |

代理净盈亏较参考少1,498.68元。六笔结果一致，差异来自两笔：

- 新华制药：分钟参考10月12日09:31、14.46退出；收盘代理09:32、14.43退出，净差119.81元。
- 松芝股份：分钟参考10月12日09:31、5.44退出；收盘代理未触发，期末仍持有，计入未实现亏损，净差1,378.87元。

这说明低频采样会错过分钟内价格，不证明新引擎实际会错过同样的触达。真实实时报价可能在分钟内多次到达，目前缺少历史数据验证。

这不是旧组合完整重跑，更不是新旧实盘组合收益率：固定入场、买入分钟排除、开盘保护统一处理、未重新竞争槽位；现有阈值拟合时间与评价期重叠，当前冻结池存在选择偏差。不要将以上金额除以30万元当作新方案组合收益。

## 10月15日买入触达敏感性

仅使用本次已冻结的34只股票、截至10:21的51根完整分钟数据，不是全天回放。

- 分钟最高触达：09:31有特发信息、宏英智能、五方光电、天通股份、华脉科技五只并列，无法从分钟数据证明谁最先收到报价。
- 分钟收盘代理：普通突破单前两只参考为宏英智能36.57、华脉科技15.00，均为09:31分钟标签；同分钟以代码排序，仅供检查，不代表真实行情顺序。
- 特发信息分钟最高09:31触达，但分钟收盘首次达价到10:08。这正是不能用分钟收盘代理替代实时报价回测的例子。
- 该样本没有开盘近涨停被排除的股票，9.7%边界由规则测试验证；因子29开盘单另列理想化对照，不混入普通突破代理排序。
