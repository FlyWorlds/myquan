持仓侧状态口径（2026-10-22）

状态以数据库实际仓位和服务端交易日为准；买卖信号与持仓状态分别表达。

| 场景 | 状态 | 说明 |
|---|---|---|
| 当天确认买入，仍有股数 | 已经买入 | 买入日期等于服务端交易日 |
| 之前买入，仍有股数 | 持有 | 跨日自动切换；分批卖出后剩余股数仍为持仓 |
| 有仓位，存在有效卖出预警/挂单 | 待卖出 | 优先于普通持有；不代表已成交，卡片可显示具体卖出原因 |
| 当天买入且T+1不可卖 | 已经买入 | 角标可显示持有·T+1、止损已记；可用数量和执行判断仍沿用原规则 |
| 确认全部卖出 | 今日平仓/已平仓 | 必须已有成交、股数归零，不能把触发卖出信号当成平仓 |
| 无仓位，有待执行买入信号 | 待买入 | 触买不等于买入成交 |
| 无仓位，无待买信号 | 空仓 | 不因为策略虚拟账本持有而显示实际持仓 |
| 有仓位，买入时间缺失 | 持有 | 不猜测当天买入或T+1限制 |

普通持仓角标不再被旧的“已经买入”预警覆盖。日期取服务端clock/交易日，避免浏览器时区及旧行情日期改变状态。数据库合并时即使股数与成本不变，也会重新判定日期；新交易轮次不继承上轮待卖出标签。此处均是展示修正，不改变资金、成交、持仓数量和卖出执行条件。

核验实例：天通股份600330，数据库买入时间2026-10-21 09:47:45，2026-10-22仍有2500股，可用2500股，显示持有；金安国纪存在待开盘卖单，保留低开峰值回落·待开盘卖出提示。
