## 定义

- **窗口**：仅 `09:20:00 ≤ 行情时刻 < 09:25:00`（不可撤单竞价）。9:15–9:19 与 9:25 核定开盘本身都不进信号。
- **基准**：该窗口内**第一个有效指示现价**。
- **买触发**：窗口最高 ≥ `ceil(基准 × (1 + 个股阈值))`。
- **卖触发**：窗口最低 ≤ `floor(基准 × (1 − 个股阈值))`。
- **成交价**：只认 9:25 正式开盘，且须通过单股行情复核。圣阳/金安若路径已触及阈值，买入点分别是正式开盘 **18.53 / 60.00**，不是 18.35 / 59.97，也不是 `ceil(开盘×阈值)`。
- **时刻**：纸面/模拟成交记开盘铃 `09:30:00`；须已收到 ≥09:30 报价。卖出遵守 T+1。

## 禁止

- 用 9:25 正式开盘或盘中最高回填 9:20–9:25 路径（lookahead）。
- 把竞价指示价写进正式 OHLC 买卖基准。
- 接口失败、日期不一致、开盘未核定或单股复核失配时成交。
