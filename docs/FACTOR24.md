# 因子24 · 连板梯度情绪

> 研究用途，不构成投资建议。

用 **连板梯度**（`mkt_ladder_score`：连板≥2 的板数之和）和连板家数，同时做两件事：

1. **止盈目标**：低梯度收紧、高梯度上移（再与因子23 合成）。
2. **是否使用因子22**：震荡（低/中梯度）开因子22，用来接回因子1 卖飞；高潮梯度 **关掉** 因子22，避免追高再买造成磨损。

| 梯度 | 因子22 | 意图 |
|------|--------|------|
| score&lt;8 或 连板家数&lt;2 | 开 | 震荡减磨损 |
| 8～20 | 开 | 常规 |
| &gt;20 | 关 | 高潮不接回 |
