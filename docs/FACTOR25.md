# 因子25 · 30 分钟震荡减磨损

> 研究用途，非投资建议。叠在因子1 开仓/止损价上；**策略十五**在震荡/常规梯度启用。

## 规则

1. **止损确认**：连续 N 根（默认 2）30m **收盘** ≤ 当日因子1 止损价（过滤影线假破）。
2. **动态半仓止盈**：持仓峰值相对成本 ≥ arm（默认 +12%）后，**非创新高棒**且收盘相对峰值回撤 ≥ giveback（默认 5%）→ 减半；**trail 不回补**。
3. **卖飞回补**：仅**止损**卖出后，在 horizon（默认 8 根 30m）内：
   - 价在卖出价 ±band（默认 1.5%）附近；
   - 成交 ≤ 卖出价 × (1+premium)（默认 1.5%）；
   - 阳线、收盘破前棒高、且 ≥ 当日止损价（避免接飞刀）。
4. **回补窗内禁止新开因子1**；当日低点已触日线止损价则禁止新开。

### 半仓试探变体（研究对照）

触日线止损 → **先卖一半**；其后连续 2 根 30m 收盘站上止损 → 接回；连续 2 根仍 ≤ 止损 → 清完。  
东财 **1 分钟**通常仅近数日；完整窗用 **5 分钟**触价。同窗对照见 `half_probe_report.md`（该样本上半仓试探弱于「先确认再卖」）。
