# 因子19 · 低开反包

> 研究用途，非投资建议。本身是选股+执行口径，需与因子18 择时组合。

压力日（因子18：中证1000 低开开盘跌停家数 ≥ 1）对未封跌停的低开股：

- gap = 开盘 / 昨收 − 1 ∈ [−8%, −0.5%]
- 开盘价买入（不追涨）
- T+1 收盘清仓；一字跌停无法卖则顺延
- 排序：gap 越负越优先，每日最多 3 只

开盘即可观测家数与 gap，无未来函数。
