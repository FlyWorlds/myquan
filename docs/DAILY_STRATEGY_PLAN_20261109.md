# 日线策略研究与迁移计划

日期：2026-11-09。状态：研究计划，尚未修改或启用交易规则。

## 目标与范围

把日常交易决策转为“收盘后判断，下一交易日执行”，减少分时毛刺导致的反复卖出和重新买入。以扣费后收益、最大回撤和换手率共同评价，不以胜率或单周收益决定上线。

暂按本轮讨论保留一个独立的早盘保护候选：隔夜可卖仓在09:30—09:35跌至正式开盘价99%时触发卖出。它是日线策略之外的执行保护，不参与日线选股。此前讨论不代表该窗口已上线；现有实现仍是09:30—10:00，实施时必须明确切换边界。纯日线、不带这条保护的版本也纳入比较。

本轮仅编写计划；不修改生产配置、持仓、历史成交或通知任务。

## 第一阶段：冻结基线与补齐数据

1. 以当前实际代码及配置冻结基线，记录策略1/16股票池、买卖规则、仓位约束、费用和版本。文档与代码不一致时查明差异，不依旧研究脚本猜测现行行为。
2. 盘点日线历史，目标覆盖2020—2026年并包含不同涨跌阶段，以实际可获得且完整的数据为准；不完整期间单列。
3. 股票池采用当时可知的成分与筛选信息，包含退市、停牌等历史状态。若只有当前池，只能标注为固定池探索，不能据此宣称全市场有效。
4. 指标用一致的复权口径，成交用当时未复权价格，并处理分红、拆合股和成本调整；历史计算不得混入未来公司行动。
5. 日线版本可在长周期研究；首五分钟保护需要分钟或更细数据验证，不允许凭日线最低价判断09:35前是否触发。现有8天分钟样本只能做短窗口诊断。

交付：数据覆盖与缺失清单、冻结基线、可复现配置。

## 第二阶段：先迁移卖出，再迁移买入

### 2.1 先评估日线卖出

先固定同一批买入事件、初始持仓与仓位大小，比较原卖出逻辑和日线卖出逻辑，隔离卖出规则的影响。固定事件实验中的买入仅在无重复持仓、资金允许时执行，并记录被跳过原因；该实验是机制诊断，随后必须进行完整组合回测。

第一版只研究一条简单趋势退出：收盘价低于当日MA10，收盘后生成卖出意向，下一交易日执行。不叠加盘中峰值回吐、半仓阶梯等规则，避免名义日线而实际仍由分时规则主导。

MA10是预先指定的研究起点，不是已验证的最佳参数；MA5/MA20仅用于稳健性检查，禁止看到测试期结果后逐股选最优参数。

对现有成本硬止损单独标记：纯日线组禁用盘中价格退出；带风控组明确列出早盘保护及是否保留成本硬止损。二者不能混成同一口径。账户/成交安全约束始终保留。

### 2.2 再评估日线买入

卖出实验完成后，再接入最简日线入场候选：

- 当日收盘价严格高于此前20个交易日最高价，且收盘价高于当日MA20时，生成买入意向。
- “此前20日”不含当天，信号仅在当天收盘且数据完整后确定。
- 下一交易日执行，不按已知收盘信号回填当天收盘成交。
- 候选多于空位时，以突破幅度排序，股票代码作固定平局顺序；排名只用信号日已知信息。
- 持仓不重复加仓，同日卖出的股票不再买入。

这是用于检验日线趋势方向的起始候选，不是收益承诺。若该方向未通过验证，保留失败结果再更换假设，不堆叠过滤条件修饰曲线。

## 第三阶段：执行与风控契约

- 收盘后：待正式日线完整到齐，计算信号，保存信号日期、数据截止时间、理由、目标数量及规则版本。行情缺失不生成猜测信号。
- 次日执行：先卖后买。日线回测以次日开盘价加费用及滑点作为代理；实际执行以真实可成交价记账。若未来使用竞价委托，必须在竞价前形成意向，不能看到正式开盘价后声称成交于开盘价。
- 买入意向仅对下一交易日有效，不能成交则取消并待当晚重算；退出意向未成交时保持待退出状态，下一可交易时段继续处理。
- 早盘保护候选使用正式开盘价，不用盘前指示价；触发后只提交一次退出请求。日线卖出已完成则撤销保护，未完成则合并退出意向，禁止重复卖出。
- 原有T+1、停牌、涨跌停可成交性、人工锁仓、现金不足、整手与数量约束继续生效。跳空和跌停不能假定按止损线成交。
- 初版研究沿用最多5只、单票目标不超过20%、每日最多2只新开等现有约束；以冻结配置核验为准，先不同时优化仓位。
- 手动锁仓、退出失败、缺失行情均留独立日志；不把未成交意向计成成交。

## 第四阶段：分组回测

| 组别 | 买入 | 常规卖出 | 日内价格保护 | 用途 |
|---|---|---|---|---|
| A | 冻结现行规则 | 冻结现行规则 | 现行规则 | 基线 |
| B | 固定买入事件 | 日线MA10退出 | 无 | 隔离日线卖出的影响 |
| C | 日线突破候选 | 日线MA10退出 | 无 | 纯日线完整组合 |
| D | 与C相同 | 与C相同 | 仅09:30—09:35开盘−1% | 检验早盘保护增益 |

B仅作机制诊断，不直接与完整组合收益混为一谈。若保留成本硬止损，作为D的另一个独立版本，并事先冻结阈值。C与D只能在两者共同具备所需数据的区间做保护效果比较；长日线回测和短分钟回测分别报告。

统一初始资金、费用、滑点模型、股票池与可交易条件，报告收益、最大回撤、回撤恢复时间、收益回撤比、换手率、平均持仓天数、交易次数、单笔尾部亏损及资金暴露。成交额不足或跌停卖不出的事件单列。

训练/验证/最终测试按时间顺序划分：若2020—2026覆盖充足，可先研究2020—2023、验证2024，再逐年向前检验。2026年10—11月已多次看过的样本不得再称为未见测试集；最终测试选尚未用于改规则的历史段或后续新增交易日，进入前冻结参数。

进行按年、上涨/下跌阶段、个股集中度、费用与滑点加倍、参数相邻值检查。检查去掉最好一天或最好一只股票后结论是否反转。原8天研究已出现单日驱动优势，不将其直接外推。

交付：逐笔交易、日度权益、分组结果、成交限制清单、可复现脚本，以及支持或否定迁移的结论。

## 第五阶段：模拟运行与迁移门槛

先在独立模拟账本连续运行至少20个交易日；若触发样本很少则延长。20日只验证运行流程，不构成收益有效性的证明。

进入模拟前：时间因果、复权、T+1、不可成交处理和账本对账全部通过；候选在未用于调参的验证段，扣费后表现和回撤达到事先冻结的目标，且换手确实减少。具体可接受的收益损失与回撤上限在看验证结果前写入研究配置，不能事后移动门槛。

接入运行时：让日线信号与日内保护走同一退出协调入口，逐项梳理现有全局quote_exit规则，避免隐式继承旧的高频退出。记录规则版本、支持一键回到冻结基线；回退仅影响未来决策，不改写已有成交。

只有回测和模拟均通过，才准备迁移配置、影响清单与回退步骤。正式切换另行明确，不因完成计划自动替换现行策略。

## 工作顺序

1. 数据与基线审计。
2. 日线卖出对照，明确是否值得继续。
3. 日线入场与完整组合回测。
4. 在具备分钟数据的共同窗口检验早盘保护。
5. 冻结候选并模拟运行，再决定迁移。

首要任务是第二步之前的数据核验和固定买入事件实验，先回答“减少盘中卖出，能否改善持仓结果”，再增加日线选股工作。
