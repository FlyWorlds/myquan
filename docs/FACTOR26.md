# 因子26 · 多层止盈

> 研究用途，非投资建议。**策略一主执行因子**（买同开盘突破；卖按浮盈分三段）。

## 规则

1. **买入**（过滤同因子1：前日阴/小阳、禁双阳跨日≥5%、T+1）
   - **开盘阈值**：当日最高 ≥ `ceil(开盘 × (1 + entry_pct))`；**盯盘按 1 分钟顺序**判定
   - 攻击波仅研究对照：`--buy-mode open_or_attack`（产物加 `_attack` 后缀，不覆盖默认 `REPORT.md`）
   - 空仓「将买入/待买入」：现价距**开盘突破买点** ≤1%；生产关闭攻击波时**不用**下砸低点派生价（避免一字开板后再触「待买入」误报）
   - 空仓**不**把「现价≤开盘派生卖价」标成「已触止损」（无仓无可止；止损触达仅实仓/纸面持仓 + 1m path）
2. **卖出（多层止盈，同分钟优先级）**
   1. **买点硬保护**：亏损达 **2.5%**；**低开已破硬保护按开盘立刻卖**（先于 T1 回落）
   2. **买入日收盘盈利 <3%（已记）**且当日尚未 **>3%** → 次日按 **max(隔夜持仓高点, 当日高点) 回落 2.5%** 全清，且不得低于买点硬保护（禁止用今开重置峰值把止损打得更低）。**昨收/昨高只经 `overnight_peak_px`**：函数自己看买入日（昨天已持有或昨天买入才并入）；漏传买入日不当隔夜峰值。今日新买（天通 2026-09-14）只用成本硬保护
   3. **大赚阶梯**：浮盈 ≥ **15%** → 可卖全清；≥ **10%** → 卖一半（不足 200 股则全清）；**已半仓后即使仍在 10% 上方也不清剩余**，留给 15% 或峰值回落 2%
   4. **中赚（>3% 且 <10%）**：**回落一半**（卖价=`floor(成本+0.5×(买入后最高−成本))`）与 **动态高点回落 0.5×近20日日频σ** 并行；从峰值往下**谁先碰到走谁**（同分钟若两线都打穿，成交价更高的那条）。波动 = akquant `vec_log_returns` + `vec_rolling_std`（点时点、不含当日）
   5. **买入当日已记**：收盘盈利 **≥3% 不记**；其余都记（含小亏、盈利 <3% 的小赚）
   6. **大赚后回落 2 个点**：峰值浮盈 ≥10% 后，`floor(峰值×0.98)` 触达 → 清仓（同分钟若同时触 10% 半仓，优先档位）
   - 触达按 **1 分钟 K 顺序**；禁止用全日 low 对抬高后卖价；**已平仓留痕成交价走 `first_session_exit_fill`**（策略统一，无个股特例），禁止用收盘后抬高的止损去撞今开
   - **持仓峰值 `peak_high`（lifecycle HWM）**：只升不降；主路径=1m `running_high`；**隔夜仓**可并入行情 API 当日 `high`（新浪字段 / 东财 `f44`）以补漏 tick，但 **09:15–9:30 竞价与 09:30–09:32 开盘脏窗** 的 API high 若高于今开/现价/1m 最高视为虚高，走 `usable_session_high` 丢弃（中国宝安 7.03@09:15）；**买入当日禁止**用 API dayHigh（可能含建仓前高点）。`overnight_peak` 开盘冻结，不因盘中 dayHigh 改写（防开盘保护污染）；今日竞价戳抬上的 `peak_high` 会压回已印出价
   - **T+1 当日**：不卖；峰值只从买入之后算，未卖出前创新高则抬升。盯盘「止损已记」唯一落库口：只记硬保护或收盘未到 3% 的哨兵价（≤成本）；盈≥3%/涨停/中段卖价/今开撞抬高止损 **不得**记、不得写回。**t1_trail 哨兵价=成本**：盘中小幅浮盈不得按「现价>哨兵×1.005」作废已记（否则次日无法武装峰值回落 2.5%，卖出侧会错误锁死在成本硬保护）
   - 次日：仅当昨日已是策略持有或策略买入，才用隔夜高点回落 2.5%（地板=买点硬保护）；低开破硬保护/开盘已破中段保护按开盘卖（**竞价核时刻 09:30**，不用首根 1m 的 09:31/09:32）；过 3% 走中段；过 10% 走分段
3. **三槽组合**：物理 3 槽（盘中/隔夜均可持 3）；当日最多买 3；当日有卖出（含半仓）通常禁再买该票。**策略十六例外**：前一日止损已记、次日竞价低开走开盘保护全清后，当天过门触买允许回补（仍占当日新增额度；盘中路径止损 / 半仓 / 因子22 不走此例外）。**先平再买**：平仓腾槽后，平仓前已触买且现价 ≤ 买点 +1% 的优先入槽（成交价=现价）；都不满足则其后新触发按时间入槽（成交价=买点）。**三槽 1m 回测**与**盯盘**均按 10% 半仓后继续止盈剩余：持仓记 `tp_stage` / `last_tp_ts`，半仓后从触达分钟下一根继续（**不再因仍在 10% 上清剩余**；走 15% 或峰值回落 2%）。不接券商，本地只记信号与纸面数量。未触达工作卖价走 `working_stop_price`（过 10% 展示峰值回落 2%，禁止 dummy OHLC 撞阶梯）。对账回测权益按 `strategy.costs` 扣费。
4. 默认 `entry_pct=2.5%`，中段门槛 `3%`，`ladder 10%/15%`，大赚回落 `2%`，回落一半 `50%`，波动回落 `50%×20日日频σ`，T1 峰值回落 `2.5%`，硬保护 `2.5%`

口径：超 10% 分段止盈；3–10% 回落一半与波动回落赛跑；买入后未站上 3% 则次日用峰值回落 2.5% 防回吐。
