# 因子26 · 浮盈回落一半止盈

> 研究用途，非投资建议。**策略一主执行因子**（买同开盘突破；卖由峰值回落阈值改为浮盈回落一半）。

## 规则

1. **买入**（两条任一，过滤同因子1：前日阴/小阳、禁双阳跨日≥5%、T+1）
   - **开盘突破**：当日最高 ≥ `ceil(开盘 × (1 + entry_pct))`；**盯盘按 1 分钟顺序**判定，禁止用全日 high/low 假攻击波
   - **攻击波**：按分钟维护 running_low；**先用此前最低算买点，再更新本分钟最低**（禁止同一根 K 的低+高自造攻击波）
2. **卖出（浮盈回落一半）**
   - **已浮盈**：`floor(成本 + 0.5 × (持仓最高 − 成本))`（峰值浮盈回吐一半出场）
   - **未浮盈**：`floor(成本 × (1 − hard_pct))` 成本硬保护，默认 `hard_pct=2.5%`
   - **触达判定**：按 **1 分钟 K 时间顺序**——先用「此前最高」算卖价，再看该分钟最低是否跌破，然后才抬升 peak
   - **禁止**用「全日最低 ≤ 抬高后的当前卖价」
   - **实仓**：路径从**买入时刻**起算；持仓峰值写入 `peak_high`（跨日延续）。**禁止**把当日快照 high 种进峰值种子。末根 1m 若已是当前分钟，不再用现价去撞「含本分钟 high」的卖价
   - **T+1 当日**：持仓状态固定「已经买入」，不进「待卖出」。若已触止损 → **止损已记**（只是触发记录）
   - **次日可卖**：**低开跌破已记价 → 开盘市价卖**；**高开不立刻卖**，从开盘再下杀 1% 才卖，否则继续浮盈回落一半。禁止按昨日已记价虚构成交。对照见 `backtest/strategy1_pool_1m/NOTED_NEXT.md`
   - **三槽组合**：物理 3 槽（盘中可持 3）；当日最多买 2；尾盘空 1（隔夜最多 2）；当日止损/已记卖出禁再买
3. 默认 `entry_pct = 2.5%`，`giveback_ratio = 0.5`，硬保护 `2.5%`

## T+1「止损已记」（盯盘与 1m 回测同一套）

A 股当日买入不可卖。止损触达只表示**出场条件已成立**，不是已经卖掉。

| 情形 | 实盘怎么做 | 本仓库 |
|------|------------|--------|
| 当日买入、未触止损 | 拿着，明日才可卖 | 同左 |
| 当日买入被套并触止损 | 卖不出，记下 | `stop_noted` + 已记价（仅记录） |
| 同日先卖旧仓再开新仓 | **禁止**再买该票 | `sold_today` → 当日禁买 |
| 次日低开继续下杀 | 开盘已跌破已记 → 按开盘价卖 | 成交=开盘价（不是已记价） |
| 可卖日低开穿透止损价 | 开盘已低于止损 | 成交=开盘价（禁止虚高用止损价） |
| 次日高开/反弹 | 不立刻卖；从开盘再设下杀阈值（默认 1%） | 触及则卖；未下杀则继续因子26 |
| 次日一字跌停封死 | 卖不出，等开板 | `locked` 时不成交；开板按跌停/开板价 |
| 盯盘错过开盘（午后才处理） | 当时能成交的现价 | 9:35 后用 last |

研究用途，非投资建议。
