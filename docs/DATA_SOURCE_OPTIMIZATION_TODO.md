# 数据源与市场事实优化清单

> 来源对照：quotapass 页面声明使用东方财富、腾讯行情、同花顺、新浪、财联社等免费公开接口。本项目先把这些能力拆成可复用数据源层，再逐步接入盯盘与策略。

## 已完成基础

- [x] 新增 `market_data_sources/` 独立数据源层，不直接改交易内核。
- [x] 新增东财涨停池解析与抓取入口：`market_data_sources.eastmoney.fetch_limit_up_pool`。
- [x] 新增新浪/腾讯行情行解析，统一成 `QuoteRecord`。
- [x] 新增多源行情对账：`compare_quote_records`，关键价格字段不一致时输出 `block_trading` 级问题。
- [x] `QuoteHub.quote_health()` 输出 `dataSources` / `sourceAges`，快照可展示当前行情来源与各源年龄。
- [x] 健康分级新增 `source_disagree`，多源关键字段冲突时按阻断交易处理。

## P0 · 建议优先做

- [ ] 把东财涨停池落地成每日缓存：`data_cache/market_facts/limit_up/YYYY-MM-DD.json`。
- [ ] 在 WatchSnapshot 增加 `marketFacts.limitUp` 摘要：涨停家数、炸板数、连板高度、首封时间分布。
- [ ] 在策略8“当日涨停定题材”里优先使用东财官方涨停池，新浪/日线只作为兜底。
- [ ] 对热池股票做新浪 vs 腾讯 vs 东财 SSE 抽样对账；出现 `source_disagree` 时只阻断自动买卖，不清空展示。
- [ ] UI 顶栏/诊断区展示 `dataSources`、`sourceAges`、`source_disagree` 明细。

## P1 · 市场事实增强

- [ ] 接东财龙虎榜与席位明细，落每日缓存，供策略17和席位标签使用。
- [ ] 接同花顺涨停揭秘/热点题材，先做说明标签，不直接参与买卖。
- [ ] 接财联社快讯后端缓存，避免浏览器 CORS 导致页面不稳定。
- [ ] 做“数据质量日报”：行情源成功率、日线缺口、涨停池数量、龙虎榜发布时间、板块源降级。
- [ ] 给策略16B增加事实过滤条件：近 N 日龙虎榜、题材热度、涨停池所属题材、炸板风险、解禁风险。

## P2 · 中期能力

- [ ] 增加解禁、两融、北向、基金持仓等风险标签；先展示，后续再评估是否进入策略。
