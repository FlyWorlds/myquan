# 策略八·题材联动 — 回测报告（研究）

> 区间：**2025-01-02 → 2026-08-11** · 中证1000 · 100万/10仓 · T+1 出场 · **非投资建议**

## 规则（v3 · 当日定题材）

| 项 | 说明 |
|---|---|
| 题材 | **当日**收盘涨停池 → 通达信概念共振 `theme_lu_count ≥ 3` |
| 股池 | 默认 `linkage`：热题材内**非当日涨停**的联动票（排除龙头） |
| 买卖 | **当日**开盘 ±阈值突破即买；T-1 情绪门槛（连板≥2、最高板 2～5） |
| 因子15 | 默认**关闭**（直接阈值买，不过低开带） |

### 回测与实盘差异

日线回测用「**当日收盘涨停**」反推题材，同日用 high 判断是否触达买点；盯盘则用**盘中实时涨停**定题材。存在近似/前视差异，仅供研究对照。
