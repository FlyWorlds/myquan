## 相对盈亏比口径
- 盈利笔落后 lag = max(0, 持股收益 − 策略收益)
- 亏损笔防守 def = max(0, 策略收益 − 持股收益)
- **相对盈亏比** = 亏损笔均 def ÷ 盈利笔均 lag（越大越好）
