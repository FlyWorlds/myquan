# 近期前高前低变体

> 研究用途，非投资建议。B&H=区间首末日 30m 日收。

## 规则

- **前高/前低**：日线近 N 日（不含当日）

- **建仓**：因子1

- **止盈**：触前高后，自峰值回撤 3% 减半（默认）

- **止损**：连续 2 根 30m 收盘 ≤ max(前低, 当日F1止损)

- **接回**：2 根站上前低且接近卖出价
