- **生成时间**：2026-08-25  
- **回测区间**：2020-01-01 → 2026-08-25  
- **标的**：天通股份（sh600330，开盘±3%）、凯盛科技（sh600552，开盘±2.5%）  
- **引擎**：akquant OpenBreak3，T+1，仅因子1 买卖；费用/滑点沿用默认

## 1. 方案定义

| 代号 | 方案 | 规则要点 |
|------|------|----------|
| A | 基线仅止损 | 开盘突破买入；仅开盘−pct 止损全清；不止盈 |
| B | 三态 15/10 | 观察池等权三态；牛市不止盈；震荡 15% / 熊市 10% 全清；触发=`prev_high`（昨高触及→今开卖） |
| B2 | 三态 20/15 | 同上，档位放宽为震荡 20% / 熊市 15% |
| C | 因子4 | 个股 `roc_ma`/`roc` 二态牛市；牛市内放宽止损（标的专用参数） |
| D | 三态15/10 + F4 | B 与 C 叠加 |

**三态行情（观察池 = 凯盛+天通等权）**

- 牛：收盘 > MA60 且 ROC20 > 0  
- 熊：收盘 < MA60 且 ROC20 < 0  
- 震荡：其余  
- **次日生效**（`shift(1)`），避免收盘偷看  

**因子4（个股）**：收盘算 ROC+均线，次日是否「牛市持股」；非牛 = 震荡+下跌合并。

## 7. 最终结论与建议

1. **正式默认（两票统一）**：继续 **A · 基线仅止损**。  
   - 全样本夏普接近、规则简单、2026 大趋势年不被提前下车。  

2. **不要默认上线**  
   - **B 三态 15/10**：天通灾难级（全样本 -734pp，2026 -53pp）。  
   - **D 三态+F4**：无协同，天通最差。  

3. **研究候选（非默认）**  
   - **凯盛 × C 因子4**：7 年中 5 年赢基线，全样本 +251pp；但 **2026 翻车（-8pp）**，样本外未验证，仅可作单票实验。  
   - **凯盛 × B2 三态 20/15**：全样本与 2026 均略好，幅度有限，且天通不适用。  

4. **天通**：所有改卖点/F4 变体在全样本与 2026 均不如基线 → **保持仅止损**。  

5. **组合层**：若凯盛+天通等权，应用统一基线，避免「一票优化、另一票毁掉」。
