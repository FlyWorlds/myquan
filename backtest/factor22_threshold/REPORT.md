# 因子22 门槛专项分析

> 研究用途，非投资建议。规则：因子1 止损后，收盘 ≥ `low×(1+bounce_pct)` 同日再买。

## 门槛含义

- **bounce_pct**：自当日最低价反弹多少才算「站稳」再买。
- **默认 1%**：`close ≥ low×1.01`。
- 越低越容易再买（次数多、易再止损）；越高越挑（次数少）。

## 读法

- 再买后再止损率接近 1 → 多数只是多挨一轮手续费/滑点。
- 看 **Δ基线** 与 **再买次数**：阈值过松时收益虚高但回撤与再止损也升。
- 凯盛/天通近期窗样本短，门槛结论以 2026YTD 为主。
