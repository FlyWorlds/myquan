# 策略3手动监控扫描

在策略3面板点击“扫描中证1000监控票”启动；打开页面、读取状态不会自动扫描。

范围只取中证指数官方000852成分表，剔除ST/退市标识、科创板、创业板、新三板及其它非沪深主板代码，不合并中证500或旧策略16名单。2026-10-22成分表1000只，按当前名称缓存与官方名称过滤后645只。每次点击重新读取成分并更新日线，实际数量可能变化。

日线相邻下笔破底分型A，在当前结构有效且破位后最多20个交易日内进入“破前低预警”监控列表；满足因子30/31/32的放量、下影止跌及风险价位条件，再标记“鲍鱼捞饭”。监控名单包含此前已破位但仍在有效窗口内的票，不全是当日首次破位；鲍鱼入场因子窗口仍为10日。预警不等于买点，不自动交易。当前破位预警使用日线已完成数据，不是盘中实时成交信号。

旧池已清空；旧研究报告保留。初始snapshot.json为空，仅手动扫描完成后写入结果。缺失、过期、历史不足与请求失败分开统计，不当作未触发信号。扫描进度见job.json，完整数据来源、剔除数量、监控名单与参数哈希见snapshot.json。缓存读写不改其它策略股票池。

GET /api/strategy3/scan 只读状态与面板；POST同路径启动后台任务。重复点击复用运行任务。前端显示进度并禁止重复点击；任务失败显示原因，可重试。每日首次/行情未缓存时需要逐票补历史，耗时取决于供应商。

## 扫描性能

行情接口内部保留AkShare/V8进程内安全锁，改为6个spawn独立进程并发处理股票，下载和CZSC计算互相隔离。已有至少120根完整日线且日期齐备时复用本地行情；结构特征按输入哈希复用。更换参数仍重新判定信号；过期行情仍需补齐，不以加速为由放行。进度由主任务统一写入，最终结果按代码排序，不受进程完成先后影响。
