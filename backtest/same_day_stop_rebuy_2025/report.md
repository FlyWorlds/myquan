# 止损当日尾盘再买扫描（2025至今）

## 规则

- **基线**：因子1开盘突破；止损当日禁买（现行）。
- **再买**：当日止损清仓后，尾盘满足条件按**收盘价**再建仓；新仓当日不可卖（T+1）。
- **过滤**：收阳；收盘≥止损×(1+X%)；(收−低)/开≥Y%。**1点=1%**。
- 触止损且收阳时，收盘天然高于止损约≥2.5点，故「收阳+X≤2.5」≈仅收阳。
- 个股阈值：东材/珠峰/凯盛 ±2.5%；天通/金安 ±3.0%；ETF 买2.5%/止3.5%。
- ETF：589080 自2025-03-05、588170 自2025-04-08（新浪日线）；个股自2025-01-02。
- **仅供研究，不构成投资建议。**

## 结论摘要

1. **仅收阳再买**：5 只个股 + 588170 均弱于基线；**589080** 样本内收益/夏普改善（+9.9% / +0.14）。多数情况下止损日空仓等下一买点更好。
2. **不限阴阳乱接**：同日买卖次数大增，多数标的夏普下降；不宜作为默认。
3. **个别改善**：西藏珠峰「不限阴阳+止损上1点」、589080「距低≥1点」样本内有超额；东材/凯盛/金安等最优变体仍接近或弱于基线夏普。
4. **建议**：默认维持「止损当日禁买」；若试验再买，优先 **589080** 或单票严格过滤（收阳且 ≥3–5 点），勿全池一刀切。

仅供研究，不构成投资建议。
