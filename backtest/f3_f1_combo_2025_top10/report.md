# 因子3×因子1 组合回测：Top10 · 2025至今

研究用途，不构成投资建议。

## 设定

| 项 | 值 |
|----|----|
| 组合 | 因子1前置（阴/小阳 + 禁双阳跨日≥5%）→ 因子3 dual 反转选股 → 因子1突破买/止损卖 |
| 股票池 | 中证500+1000 主板并集（1004） |
| TopK | 10 |
| 区间 | 2025-01-02 → 2026-08-26（400 交易日） |
| 预热 | 2024-01-01 |
| 因子3 | dual rev n=90 + n2=40（等权 z） |
| 因子1 | entry/stop = 2.5%；无到期（只止损） |
| 初始资金 | 1,000,000 |

## 结果

| 指标 | 数值 |
|------|------|
| 累计收益 | **+4.05%** |
| 最大回撤 | **26.80%** |
| 夏普 | **0.230** |
| 买入笔数 | 558 |
| 止损卖出 | 551 |

### 分年

| 年 | 收益% | 最大回撤% |
|----|-------|-----------|
| 2025 | +23.87 | 10.42 |
| 2026 | -16.00 | 26.80（至 8/26） |

## 解读（简）

- 2025 全年尚可（约 +24%、回撤约 10%），2026 至今拖累整体至约 +4%。
- 未触发突破次数远高于成交笔数，说明「选入名单 ≠ 次日冲到 +2.5%」。
- 几乎全部以止损结束（551/558），持仓偏短、换手高。
