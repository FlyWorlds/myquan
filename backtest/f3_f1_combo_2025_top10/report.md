# 因子3×因子1 组合回测：Top10 · 2025至今

研究用途，不构成投资建议。

## 设定

| 项 | 值 |
|----|----|
| 组合 | 因子1前置 → 因子3 dual 反转 Top10 → 因子1突破买 |
| 卖出 | **分档止盈 +15/20/25% 各减初始仓 20%**（相对买入价、high 触发）+ 余仓开盘−2.5% 止损 |
| 股票池 | 中证500+1000 主板并集（1004） |
| 区间 | 2025-01-02 → 2026-08-26（400 交易日） |
| 预热 | 2024-01-01 |
| 因子3 | dual rev n=90 + n2=40 |
| 初始资金 | 1,000,000 |

| 指标 | 仅止损 | +分档止盈 |

| 累计收益 | +4.05% | +3.27% |

止盈触发偏少（76 次减仓 vs 558 笔买入）：本组合持仓短、多数票先触 −2.5% 止损，很少摸到 +15%。2025 止盈略增厚，2026 反而略差，整体略逊于仅止损。
