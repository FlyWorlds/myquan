# Q51 7.4.0 看板录制讲稿

建议时长：3 分 20 秒左右。录制前在 BUILD 根目录运行 `python scripts/demo_html.py`，再打开 `validation/skill_demo.html`。它只读取已有生产 Parquet，不会触发 Panda Data 查询。不要展示账号、密码或 Panda Data 认证环境变量。

## 00:00–00:25 先说工具边界

“这是 Q51 克拉曼特殊情况研究 BUILD。它把定增解禁、重组借壳、分拆上市和困境反转做成事件研究入口。这里的研究优先级不是买入信号，只有完整承保门通过的原始事件才可以继续供 Alpha 使用。”

## 00:25–01:25 今日研究候选

滚动到“今日研究候选”，依次指出排名、证券代码、事件日期和分数。说明规则：最低 60 分、总榜最多 5 只、每类最多 3 只，不足时不凑数。

“困境反转看风险警示状态、利润、利润改善、经营现金流、审计质量、当前价格和事件时效。重组与分拆看证券映射、证监会催化剂、明确关键词、当前财务、审计、价格和时效。每张卡都保留正向信号、风险标记、待补证据和下一步动作。”

重点放大一张卡的“承保状态：承保证据不完整”。

“高分只代表值得先研究，不代表承保已经通过。比如资本结构、交易条款、保守价值和失败价值仍然缺失时，卡片不会变成合格特殊情况。”

## 01:25–02:10 独立风险观察

滚动到“独立风险观察”。

“风险观察与机会榜分开。定增解禁只放在这里，计算解禁占流通盘比例、参与者浮盈、距解禁日天数，以及按 20 日平均成交额估算的消化天数。困境风险则观察仍生效的风险警示、审计警示、财务核验失败、负经营现金流和股东减持。”

强调“定增发行价是参与者历史成本，不是二级市场买方可以获得的成本”，因此不把定增折价包装成套利机会。

## 02:10–02:35 评分贡献与补证动作

展示“评分贡献”和“风险与补证动作”。

“评分贡献把候选分数拆开，方便复核规则是否被正确执行。补证动作是下一步研究清单，例如补齐交易条款、建立保守估值、建立失败情景价值、核对资本结构和流动性。”

## 02:35–03:05 P0–P4 与审计区

向下展示 P0–P4、承保漏斗、事件复核队列。

“P0 到 P4 是生产审计链：接口治理、可恢复运行、官方证据包、点时回放和生产告警。研究榜使用决策日前最新公开证据；历史回放只使用事件时点可见证据，两个口径禁止混用。”

## 03:05–03:20 接口与事件说明

快速展示接口说明和事件解释说明。

“看板底部保留所有 Panda Data 接口的中文用途、字段边界和四类事件解释。页面只读取生产 Parquet 和运行报告，不会因为打开看板再次调用 Panda Data。”
