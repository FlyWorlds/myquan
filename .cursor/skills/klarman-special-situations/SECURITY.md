# 安全说明

## 凭证与敏感数据

Panda Data 凭证只能在本地进程环境中短暂使用，不能写入代码、Markdown、Parquet、日志、Issue、Pull Request、Release 说明或视频画面。

不要提交以下内容：

- `PANDA_DATA_USERNAME`、`PANDA_DATA_PASSWORD` 或访问令牌。
- 交易账户、个人身份信息、未脱敏的内部数据或系统配置。
- 服务端错误原文中可能包含的敏感字段。

## 发现泄露时的处理

1. 立即停止传播相关文件和提交。
2. 立即在上游服务撤销或轮换受影响凭证。
3. 通过仓库管理员约定的私密渠道报告，不要在公开讨论中粘贴敏感内容。
4. 从 Git 历史、Release 资产和本地交付包中移除泄露内容后，再重新完成验证与发布。

## 文档与交付安全

- 文档和提交信息必须以 UTF-8 保存与发布，避免中文内容在仓库页面中被错误显示。
- 演示视频、截图和日志必须在上传前检查，确保不包含账号、密码、令牌、环境变量或原始服务端错误内容。
- 生产 Parquet 只作为经验证的快照交付；不得以手工修改或未经核验的数据替换。

## 结果使用边界

本 Skill 的研究候选和风险观察均不是交易指令。只有通过完整承保门的原始 `qualified_special_situation` 事件行才允许后续 Alpha 消费，且仍需由调用方独立处理组合、风险与合规约束。
