# 风险分类学 (risk-taxonomy)

本 Skill 覆盖 7 类 A 股治理/监管风险。每类给出定义、数据来源、严重度基准与依据。

| 风险 | 基准分 | 依据 |
|---|---|---|
| ST / *ST | 80 | 交易所风险警示，直接影响流动性与退市预期，最高优先级 |
| 停牌 | 70 | 无法交易 = 流动性冻结；长期停牌常伴随重大不确定性 |
| 股权冻结 | 60 | 前十大股东股权被司法冻结，指向诉讼/债务风险 |
| 股东减持计划 | 55 | 最直接的抛压信号；大股东减持信号强于高管 |
| 限售解禁 | 45 | 潜在供给冲击；临近解禁（≤30天）风险显著上升 |
| 股权质押 | 40 | 累计质押占比高 → 平仓/控制权风险 |
| 被举牌 | 25 | 中性偏事件，可能伴随股价波动与治理博弈 |

## 因子说明

**规模因子**
- 减持：`ratio_up_limit`（占总股本%），1% 记满。
- 质押：`acc_pledge_total_ratio`（累计质押占总股本%），30% 记满。

**时间邻近因子**（半衰期衰减）
- 已发生事件：`0.5 ** (距今天数 / 半衰期)`；减持/冻结半衰期 90 天，质押 180 天。
- 未来事件（解禁）：按最高时效 1.0，且 ≤30 天额外加权。

**股东类型修正**
- 控股股东/实际控制人减持 ×1.15；高管/一般股东 ×0.9。

## 聚合公式

综合分 `= 1 - ∏(1 - subscore_i / 100)`，再 ×100。
优点：多类中等风险叠加会推高总分，而不会被算术平均稀释——符合"多个雷同时存在更危险"的直觉。

## 分级阈值

`score < 25 → low`，`25 ≤ score < 55 → medium`，`score ≥ 55 → high`。

> 所有数值为方法论默认值，可按机构风控偏好在 `scoring.py::BASE` 与阈值处调整。
