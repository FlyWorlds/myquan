# 🧩 Global Commodity Term Structure

[简体中文](README.md) | **English**

> Research the **term structure of overseas / international commodity futures** from
> **public web data**: contango vs backwardation, curve slope, roll yield, calendar and
> inter-commodity spreads, with inventory context. Term structure describes **carry, not
> a price-direction signal**.

## 📖 What This Is

A QuantSkills community **skill** an agent loads to build and read the forward curve of
**overseas commodity futures**. Input: a commodity (or a pair for a spread) + venue +
reference date. Processing: pull several real listed contract months, classify
contango/backwardation, compute the slope, estimate roll yield, compute calendar and
inter-commodity spreads, and add inventory context. Output: a factual research note with
source and as-of-date labels on every number.

**Why it exists as its own package:** Pandadata has **no overseas futures coverage** (its
coverage doc says use Yahoo / stooq / public-exchange data for foreign contracts), so this
skill deliberately does **not** call Pandadata and uses public web data only. It is also
distinct from the China-only futures skills (`futures-deepview-analyst`,
`futures-industrial-profit`, `futures-cross-variety-corr`, which read domestic
exchange/DeepView data) — this one is **overseas commodities from public sources**.

Data is read through the repository's own web tooling (the agent's browser / fetch /
search capability). **No API keys, no paid feeds.**

## 📐 Core Workflow (short)

1. Scope the commodity/venue/date; read the boundary and data-source docs first.
2. Map the commodity to a public symbol (`CL=F`/`BZ=F`/`GC=F`/`HG=F`/`NG=F`, …); record
   venue, currency, unit.
3. Pull **≥ 2 real listed contract months** (settlement preferred; label settlement vs
   last-trade with dates).
4. Classify contango/backwardation and compute the annualized slope.
5. Estimate roll yield (state the roll convention; a carry approximation only).
6. Compute calendar and inter-commodity spreads (Brent–WTI, gold/silver ratio, a
   simplified crack proxy) with formulas and units.
7. Add public inventory context (EIA petroleum, LME stocks) as qualitative color.
8. Write the factual note with a source and date label on every number.

See `references/methodology.md`.

## 📊 Data Sources & Dependencies

- **Exchange settlement/product pages**: CME / COMEX / NYMEX / ICE / LME public pages.
- **Yahoo Finance**: continuous / front-month symbols (`CL=F`, `BZ=F`, `GC=F`, `SI=F`,
  `HG=F`, `NG=F`, …) and listed months.
- **stooq**: public futures quotes for cross-check / fallback.
- **Public inventory**: EIA (petroleum), LME warehouse stocks.
- Dependencies: the repo's web tooling + Python standard library; `requires: []`.

## ⚠️ Limits & Risk Boundary

- Overseas commodities, **public web data only**; no Pandadata, no paid feeds, no keys.
- **A curve needs ≥ 2 real listed months.** Never fabricate or interpolate a month; with
  one price, say so and stop.
- **Continuous-contract splicing distorts levels** (roll gaps): state the roll convention
  and treat spliced history as approximate.
- Distinguish **settlement vs last-trade**; respect **per-exchange currency and unit
  differences**; never mix units silently.
- Inventory context is qualitative background, not a forecasting input.
- Term structure describes carry, **not a price signal**; research/educational tooling
  only — not official, certified, or verified.
- External writes (save/publish) require an explicit user trigger.
