## 📖 What This Is

An **overseas / global-markets** macro-rates-FX research skill. It breaks a "look at overseas
rates / the yield curve / the dollar and major pairs / the global macro regime" request into a
fixed four-step evidence pass plus a factual synthesis:

1. **DM rate complex** — policy rate, 2y/10y sovereign yields, the 2s10s slope, and real rates;
2. **USD & major pairs** — anchor on the broad trade-weighted dollar (`DTWEXBGS`, a DXY proxy) and
   read EURUSD / USDJPY / GBPUSD direction and consistency;
3. **International-macro layer** — delegate Pandadata `get_macro_gb` (宏观行业·国际宏观) to the
   `pandadata-api` skill and align its dates;
4. **Regime read** — steepening/flattening/inverted curve, rising/falling real rates, firm/soft
   dollar, and where the evidence agrees or diverges — all as **observations**, never forecasts.

- **Input:** region set (US required; add EUR-area / Japan / UK), lookback window, rates vs FX vs both.
- **Output:** a Chinese Markdown regime brief (summary + rate table + FX table + international macro
  + consistency/divergences + sources & vintage appendix + disclaimer).
- **How it differs from siblings:** `macro-monitor` is China-focused Pandadata macro,
  `macro-altdata-nowcast` is China alt-data; **this skill is overseas/global rates + FX from mostly
  public sources, using only `get_macro_gb` on the Pandadata side.**

## 🚀 Quick Start

```bash
cp -r skill-global-macro-rates-fx-lab ~/.claude/skills/global-macro-rates-fx-lab
```

Example trigger prompts:

```text
Show me the state of the US Treasury curve (2s10s) and real rates right now
Are the dollar and EURUSD / USDJPY / GBPUSD moving consistently? Build a global macro regime brief
Using public FRED data plus Pandadata international macro, map the overseas rates & FX regime
```

Validate a produced brief's structure with the bundled checker:

```bash
python scripts/validate_report.py your_brief.md
```

## 🧮 Data Sources & Dependencies

- **FRED public series:** `DGS2`, `DGS10`, `T10Y2Y` (2s10s), `DFII10` (10y real), `DTWEXBGS`
  (broad USD index proxy).
- **Central-bank policy pages (public):** Federal Reserve, ECB, Bank of Japan, Bank of England —
  current policy-rate level and stance (facts only).
- **Public FX references:** ECB euro reference rates and public exchange-rate hosts for
  EURUSD / USDJPY / GBPUSD.
- **Pandadata `get_macro_gb`** (宏观行业·国际宏观): the **only** Pandadata method used; the actual
  call is delegated to the `pandadata-api` skill (requires `skill-pandadata-api`). No keys ship in
  this repo.

## 📐 Limits & Risk Boundary

| Constraint | Meaning |
| --- | --- |
| 🌐 Public / user-provided sources only | See `references/source_boundary.md`; no bundled keys, no paywalled/private scraping |
| 🕒 Data lags and revises | FRED daily series can be one or more business days behind and revise — always label as-of / vintage |
| 📏 Units are load-bearing | Yields/rates in percent; spreads in percentage points or basis points (1pp = 100bp), never mixed |
| 💱 FX quoting direction | EURUSD/GBPUSD are USD-per-unit, USDJPY is JPY-per-USD; a stronger dollar sends the first two down, USDJPY up |
| 📉 Inversion is an observation | `2s10s < 0` is reported as a curve state, not a recession call or a trade |
| 🚫 Describe, not recommend | Outputs research structure and facts, not investment advice |
| 🧭 Domain boundary | Overseas/global rates + FX; use `macro-monitor` for China macro, `macro-altdata-nowcast` for China alt-data |

**Outputs stay local by default:** this repo does not commit generated briefs; results are saved
locally, and `scripts/validate_report.py` is for self-checking structure.
