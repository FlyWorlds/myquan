# Claude Code Entry Point

Read `SKILL.md` before working in this repository. It is the authoritative instruction set for execution planning, market microstructure, order-state controls, fill simulation, transaction-cost analysis, and reconciliation.

Use `README.md` for the Chinese-first project overview and `README.en.md` for the English overview. Keep event timestamps, parent-child order lineage, fill assumptions, benchmarks, costs, and residual quantity explicit.

Default to historical simulation, paper trading, or analysis. Do not submit, cancel, or modify live orders, promise returns, or provide personalized investment advice.
