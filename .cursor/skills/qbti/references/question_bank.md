# 问题库 / Question Bank（quiz_version: 1.1）

> **架构约定：包装自由，枚举固定。**
> 本文件定义五个**测量维度**。每个维度规定了（1）要测什么、（2）封闭的枚举值及其**语义锚点**、（3）默认值、（4）映射目标。这些是硬契约，不可更改。
> 至于问题用什么比喻来包装——宠物、足球、网球、健身、瑜伽、烧菜、恋爱、学外语、游戏、追剧——**完全交给 agent 现场发挥**：观察用户的兴趣和语言风格，选一个对方有感觉的比喻；用户对某个比喻无感就换一个，或者直接白描提问。各维度的「示例包装」和文末的「包装灵感库」仅供参考，不是台词本。
> 唯一的要求：问完之后，agent 必须把用户的回答归类到该维度的某个枚举值上，并向用户确认归类结果。枚举值是 `scripts/derive_profile.py` 与 `references/preference_mapping.yaml` 的唯一合法输入。

## 提问规则

1. 五个维度按 A→E 顺序覆盖，每维度至少一问（追问澄清不限次数），包装方式自选。
2. 归类依据是各维度的「语义锚点」列——不管用户说的是"弃疗卸载 APP"还是"把球票撕了"，只要意思是"受不了亏损想立刻退出"，就归到对应枚举。
3. 归类后必须复述确认：「你的意思是……对吗？」用户否认就换个问法重新问，**禁止**擅自替用户定档。
4. 用户拒答某维度时使用默认值，并记入 `defaults_used`。
5. 全部五维完成后进入总复述确认环节（见文末模板与 SKILL.md 第 3 步）。

## 维度 A：亏损反应（风险承受力）

**测什么**：面对浮亏时的真实情绪反应与行为倾向。

**固定情境要素**（包装可换，情境结构不能少）：让用户想象一笔**已经投入的钱短期内明显缩水**（基准锚点：一天 -8%），问第一反应。

| 枚举值 `cluster_a_loss_reaction` | 语义锚点：用户的意思是…… |
| --- | --- |
| `cant_sleep_sell_now` | 严重焦虑，想立刻退出止血，亏损直接影响睡眠/情绪 |
| `uncomfortable_but_check_first` | 明显不适，但会先弄清原因再决定，不会恐慌性操作 |
| `stick_to_plan` | 有点在意但既定计划优先，情绪不驱动操作 |
| `discount_buy_more` | 把下跌视为机会，倾向逢低加仓 |

**示例包装**
- 直白版：「你昨天投的钱今天跌了 8%，你的第一反应是？」
- 球迷版：「你主队上半场就落后三球，你是关电视睡觉、边骂边看完、按赛季长线看待，还是趁球票打折再买两场？」

**追问（定档用）**：「如果继续跌到 -20% 呢？」——在相邻两档间摇摆时使用。

**映射到**：`risk_tolerance`、`stop_loss_discipline`、`max_position_pct`（preference_mapping.yaml `cluster_a`）。
**默认**：`stick_to_plan`。

## 维度 B：参与度（关注与调仓频率）

**测什么**：用户实际愿意投入多少注意力来打理这笔钱。

| 枚举值 `cluster_b_involvement` | 语义锚点：用户的意思是…… |
| --- | --- |
| `daily_hands_on` | 每天都想看看账户、了解发生了什么 |
| `weekly_check_in` | 每周关注一两次比较舒服 |
| `monthly_glance` | 一个月扫一眼就够了 |
| `quarterly_set_forget` | 基本不想管，一个季度想起来看一眼 |

**示例包装**
- 宠物版：「每天遛的柯基、每周铲屎的猫、每月浇水的多肉，还是一块石头？」
- 游戏版：「你想玩每日上线做任务的手游，还是买断制单机放假才打开？」
- 直白版：「你实际能坚持多久看一次账户？说实话就行。」

**映射到**：`involvement_level`、`rebalance_frequency`、`wants_monitor_skill`。
**默认**：`monthly_glance`。

**注意**：调仓频率上限受 `skill-backtest` 标准协议（T+1 开盘成交、双边 15bp 成本）约束——`daily_hands_on` 也只映射为**周度**调仓。agent 需向用户解释：「每天看可以，但每天换股的手续费会吃掉收益。」

## 维度 C：策略口味（因子家族偏好）

**测什么**：用户天然认同哪种"赚钱的道理"。这是五维中最抽象的一维，包装比喻的作用最大。

| 枚举值 `cluster_c_taste` | 语义锚点：用户认同的逻辑是…… | 因子家族 |
| --- | --- | --- |
| `ride_the_trend` | 强者恒强，跟着已经被验证的热度走 | momentum |
| `hunt_the_overlooked` | 被埋没的好东西早晚会被发现，愿意提前埋伏等待 | mean_reversion |
| `steady_and_boring` | 不求惊喜求稳定，宁可无聊也不要踩雷 | low_volatility + quality_stable |
| `bet_on_reversal` | 物极必反，跌狠了的东西会弹回来，敢在恐慌时进场 | reversal |

**示例包装**
- 追剧版：追当季爆款 / 挖冷门佳作 / 重刷经典老剧 / 就爱大反转。
- 足球版：买当红豪门的球票 / 押注低级别联赛的潜力队 / 只看打法稳健的老牌劲旅 / 专挑降级区球队翻盘的比赛看。
- 直白版：四种赚钱逻辑各用一句话讲给用户听，问哪种"听着最像你会做的事"。

允许用户再选一个「也挺像」的备选（`cluster_c_taste_secondary`，可为 null）。

**固定追问（必问，包装可换）**：测用户对**持有标的日常大幅波动**的情绪反应。

| 枚举值 `cluster_c_volatility_stance` | 语义锚点 |
| --- | --- |
| `stresses_me_out` | 波动带来压力，希望持仓安静平稳 |
| `neutral` | 无感 |
| `energizes_me` | 波动让人兴奋，觉得有波动才有机会 |

**映射到**：`factor_affinity`（主选+备选构成 Top2）、`volatility_stance`。冲突调节由 preference_mapping.yaml `volatility_adjustments` 定义（如主选 momentum 但 `stresses_me_out` → 注入 low_volatility 并触发一致性提示）。
**默认**：`steady_and_boring` + `neutral`。

## 维度 D：选股范围（行业偏好与排除）

**测什么**：用户对"投什么行业"的开放程度与硬性排除项。

| 枚举值 `cluster_d_universe_style` | 语义锚点 |
| --- | --- |
| `familiar_only` | 只投自己大概了解是干什么的行业 |
| `explorer_no_limit` | 什么行业都行，交给数据说话 |
| `has_exclusions` | 大部分都行，但有几类坚决不碰 |

**示例包装**
- 点菜版：只点吃过的菜 / 菜单闭眼点 / 有忌口。
- 旅行版：只去去过的城市 / 说走就走哪儿都行 / 哪儿都行但绝不去某几个地方。

**追问**
- `familiar_only` → 「说说你了解或感兴趣的行业？」→ 归类到 `cluster_d_preferred_sectors`（枚举见 preference_mapping.yaml `sector_enum`）。
- `has_exclusions` → 「哪些行业你不想碰？」→ 归类到 `cluster_d_excluded_sectors`。

**固定追问（必问，直白提问，不建议包装）**：「有一类股票戴着 ST 帽子（有退市或重大风险警示），还有一些有大股东高比例质押之类的风险信号。这类『高风险高刺激』的票要不要直接排除？」→ `cluster_d_exclude_st`（bool，推荐并默认 `true`）。

**映射到**：`sector_preference_mode`、`preferred_sectors`、`excluded_sectors`、`exclude_st_and_risk_flags`。
**默认**：`explorer_no_limit` + `cluster_d_exclude_st: true`。

## 维度 E：时间周期（持有期与换手容忍度）

**测什么**：这笔钱多久之内不需要动、用户多久想看到一次"结论"。

| 枚举值 `cluster_e_time_capsule` | 语义锚点 |
| --- | --- |
| `next_month` | 一个月内就想看到结果 |
| `year_end` | 以今年为限观察 |
| `few_years` | 两三年不着急 |
| `decade_plus` | 十年为单位，长期不动 |

**示例包装**
- 时间胶囊版：「给这笔钱设一个『重新认真考虑』的开箱日，你定在什么时候？」
- 直白版：「这笔钱最快什么时候可能要用？你希望多久复盘一次它值不值得继续？」

**特别处理**：选 `next_month` 时 agent 必须提示——「一个月太短，任何因子策略在一个月内的表现基本是运气；这个工具适合至少以季度为单位的钱。要继续的话我会按最短档处理，但请确认这笔钱一个月内真的不着急用。」该提示写入 `consistency_flags`。

**映射到**：`time_horizon`、`target_holding_period_days`、`turnover_tolerance`。
**默认**：`year_end`。

## 包装灵感库（示例，非台词本）

> 每个主题给出 A–E 五个维度的问法示意。用法：整套沿用一个主题，或不同维度混搭不同主题，或以此为灵感自创——只要回答能落回各维度的枚举即可。

### 🎾 网球版

- **A 亏损反应**：比赛先丢一盘，你是直接弃赛、先分析对手打法再调整、按赛前战术打完，还是觉得对手底牌出尽正好翻盘反攻？
- **B 参与度**：每天雷打不动训练、每周约一场球、每月打一次过瘾，还是球拍在储物间落灰、想起来才摸一下？
- **C 策略口味**：学当今最火的暴力正手（跟热度）、苦练冷门切削等它重新流行（埋伏）、只打最稳的底线拉锯（求稳），还是专爱被动局面下的搏杀反击（反转）？
- **D 选股范围**：只跟知根知底的球友约球、谁约都行，还是大部分都行但有几个人绝不同场？
- **E 时间周期**：下个月俱乐部赛就要出成绩，还是以年度积分、甚至几年后的老将组为目标慢慢磨？

### 🏋️ 健身版

- **A 亏损反应**：坚持一个月体重反倒涨了 3 斤，你是弃疗躺平、先查是不是吃的问题、按课表继续，还是把它当成加练的信号？
- **B 参与度**：每天打卡的自律狂、每周三练、每月称一次体重看看趋势，还是办了年卡再没去过？
- **C 策略口味**：跟练全网爆火的网红课程、挖小众但有效的训练法、万年经典三大项练到老，还是专攻最弱部位等它逆袭成优势？
- **D 选股范围**：只做熟悉有把握的动作、教练排啥练啥，还是大部分都行但受过伤的部位绝对不碰？
- **E 时间周期**：一个月后海边度假就要见效果，还是把健身当十年的生活习惯？

### 🧘 瑜伽版

- **A 亏损反应**：一个体式练了很久反而退步了，你是当场收垫子走人、先感受身体哪里紧了、按序列不急不躁地继续，还是越受挫越想磕下来？
- **B 参与度**：每日晨练、每周两节课、每月复盘一次进度，还是垫子卷起来在墙角吃灰？
- **C 策略口味**：追新兴流派、挖还没火的古典传承、只练基础序列稳扎稳打，还是偏爱高难倒立那种绝处逢生的突破感？
- **D 选股范围**：只上熟悉老师的课、什么课都愿意体验，还是大部分都行但高温瑜伽这类坚决不碰？
- **E 时间周期**：一个月内开肩开髋见成效，还是当作十年的修习？

### 🍳 烧菜版

- **A 亏损反应**：精心准备的一道菜烧砸了，你是从此点外卖、复盘哪一步出了错、按菜谱原样再来一次，还是干脆借机改良出自己的版本？
- **B 参与度**：每天下厨、周末做饭、每月宴客露一手，还是厨房基本是摆设？
- **C 策略口味**：跟着爆款菜谱走、专挖没人知道的地方菜系、只做家常菜稳定发挥，还是最享受把快过期的食材抢救成惊喜料理？
- **D 选股范围**：只买认识的菜、菜市场看什么新鲜买什么，还是大部分都行但有几样食材绝不进家门？
- **E 时间周期**：下个月家宴就要拿得出手，还是把厨艺当终身爱好慢慢养？

### 💘 恋爱版

> 分寸提示：只用来类比**相处模式与情绪反应**，不要把"选股"类比成"选人"。

- **A 亏损反应**（感情挫折）：用心准备的表白被婉拒了，你是立刻退场删好友、先想想是不是方式不对、按自己的节奏继续真诚相处，还是相信峰回路转反而加倍投入？
- **B 参与度**：每天嘘寒问暖、每周认真约一次会、每月纪念日仪式感拉满，还是顺其自然缘分到了自然来？
- **C 策略口味**（恋爱观）：心动就轰轰烈烈冲（跟着感觉的势头走）、慢慢了解一个还没被人注意的宝藏（耐心埋伏）、要细水长流稳稳的幸福（求稳），还是相信吵完架和好后感情反而更深（反转）？
- **D 选股范围**（约会活动）：约会只去熟悉的老三样、什么新活动都愿意试，还是大部分都行但蹦极这类坚决不去？
- **E 时间周期**：下个月就想确定关系，还是把感情当一辈子的事慢慢经营？

### 🗣️ 学外语版

- **A 亏损反应**：学了三个月，模考成绩不升反降，你是弃学卸载 APP、先分析错在哪类题、按学习计划继续，还是越挫越勇加大投入？
- **B 参与度**：每天背单词打卡、每周上两次课、每月测一次水平，还是收藏了一堆课程从没打开过？
- **C 策略口味**：学当下最热门的语言（跟风口）、学小语种等它变刚需（埋伏）、把英语基本功打到扎实（求稳），还是专门捡当年半途而废的语言重新拾起（反转）？
- **D 选股范围**：只学工作用得上的、什么语言都有兴趣，还是大部分都行但有几门完全不想碰？
- **E 时间周期**：下个月出国旅游就要开口，还是奔着十年后无字幕看电影去？
