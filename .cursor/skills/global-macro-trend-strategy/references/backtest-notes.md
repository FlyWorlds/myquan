# Backtest Notes — 回测方法、坑与优雅降级

`scripts/backtest.py` 是一段**独立、仅依赖标准库 + pandas** 的研究回测。这份文档说明它怎么算、
容易踩什么坑、以及数据不全时如何优雅降级。目标是让结果**可复核、可解释、不自欺**。

## 1. 计算流程（脚本内部口径）

1. 读价格 CSV（`date, close`，可选 `open`），按日期排序、去重、丢弃非正价格。
2. 取信号列（外部 CSV 的 `value`，或内置均线交叉），与价格按 `date` 对齐。
3. 由信号算目标仓位 `weight(t)`：方向 × 仓位法（vol-target / fixed-fraction），再套风控截断。
4. **前视规避**：把 `weight` 整体后移一根——`t` 日算出的仓位在 `t+1` 才生效。
5. 计算每日收益：`ret_gross(t) = weight_used(t) * price_return(t)`。
6. 计算换手与成本：`turnover(t) = |weight_used(t) - weight_used(t-1)|`，
   `cost(t) = turnover(t) * (fee_bps + slip_bps)/1e4`；`ret_net = ret_gross - cost`。
7. 累计权益 `nav = cumprod(1 + ret_net)`，回撤 `dd = nav/cummax(nav) - 1`。
8. 指标：CAGR、年化波动、Sharpe（`CAGR/vol`，无风险利率设 0，须声明）、最大回撤、平均换手。

## 2. 前视（look-ahead）——最致命的坑

- 信号用了 `t` 日**收盘后**才知道的数据，就**不能**用 `t` 日收盘价成交；只能 `t+1`。
- 脚本用 `weight.shift(1)` 强制滞后一根。任何"当天算当天成交"都会系统性高估收益。
- 若信号本身是滚动统计（均线、z-score），确认窗口只用了 `t` 及之前的数据，没有用未来点。

## 3. 成本与滑点——高换手时成本主导

- 双边成本用 bps 表示，按换手计提。趋势策略换手看似不高，但阈值带设得太窄、再平衡太频繁时，
  换手会飙升，**净收益被成本吃掉**。
- 建议做敏感性：把 `fee_bps + slip_bps` 从 0 提到 3、5、10bps，看 Sharpe 衰减多快。若 3bps 就转负，
  说明策略的 alpha 主要是"零成本幻觉"。

## 4. 连续合约换月 & 幸存者偏差

- Yahoo/stooq 的"连续期货"（`CL=F` 等）是**拼接连续合约**，换月点会有价格跳变。回测收益里可能混入
  换月造成的假收益/假亏损，尤其对趋势信号敏感。产物须**显式标注**用的是连续合约、未做换月调整。
- 指数/外汇没有换月问题，但**幸存者偏差**仍在：只回测今天还存在、还有数据的品种，会高估整体表现。

## 5. 过拟合 & 样本外（hold-out）

- 参数（均线长度、enter/exit 阈值、vol 窗口、止损）在同一段历史上反复调，很容易过拟合。
- **做法**：把样本切成 in-sample（调参）和 out-of-sample（只跑一次，不回头调）。产物要报告样本外表现，
  并说明"样本外明显变差"是过拟合的典型信号。
- 单一参数组合的漂亮回测 ≠ 稳健。相邻参数是否也还行（参数高原 vs 参数尖峰）比单点更有说服力。

## 6. 指标口径（避免误读）

- **CAGR**：几何年化收益 = `nav_end^(annualization/periods) - 1`。
- **Sharpe**：`CAGR / 年化波动`，本脚本无风险利率取 0（须声明）；短样本的 Sharpe 噪声很大。
- **最大回撤 maxDD**：峰值到谷底的最大跌幅，反映最坏持有体验。
- **换手 turnover**：日均双边换手，估算成本敏感度与实盘可行性。

## 7. 优雅降级（graceful degradation）

- **缺 pandas**：脚本 import 失败时打印清晰安装提示并以非零码退出，不吞异常。
- **缺信号文件**：**快速失败，不静默回退**——`load_signal()` 对不存在的路径抛 `FileNotFoundError`，并提示改用 `--signal builtin_ma`（避免把打错的信号路径误当示例信号，掩盖错误）。要用内置均线交叉示例信号，须**显式**传 `--signal builtin_ma`，输出里会标注"示例信号，仅跑通"。
- **缺 `open` 列**：`t+1` 开盘成交不可用时，自动退回 `t+1` 收盘成交，并在 metrics 里记录成交口径。
- **数据太短**：periods 少于阈值（如 60）时，指标仍算但标注"样本过短，统计意义有限"。
- **全空仓**：信号恒为 0 或风控长期空仓时，NAV 恒为 1，明确提示而不是报错崩溃。

## 8. 结果解释要点（写进 results_explainer.md）

- 用大白话讲每个指标是什么、假设了什么（成本、滑点、t+1、无风险利率=0、样本窗口）。
- 明确说明：**结果是示意性的历史统计，不是预测，也不是交易建议**。
