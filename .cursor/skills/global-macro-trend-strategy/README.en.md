## 📖 What This Is

An **overseas research-strategy generator**. Give it a signal plus public overseas daily
prices, and it turns the idea into something reviewable:

- **Input**: a public overseas price CSV (Yahoo Finance / stooq continuous futures, FX,
  indices; columns `date, close`) plus a signal — a sibling overseas skill's output, your own
  `date,value` series, or the script's built-in moving-average-crossover demo signal.
- **Processing**: define the strategy contract (universe / signal→position map / entry-exit /
  rebalance) → position sizing (vol-target or fixed-fraction) → risk limits (per-symbol weight /
  stop / drawdown guard) → run `scripts/backtest.py` with `t+1` execution and realistic costs.
- **Output**: `strategy_spec.md`, `metrics.json` + `equity_curve.csv`, and a plain-language
  `results_explainer.md` (checkable by `scripts/validate_report.py`).

**How it differs**: `ssquant-*` / `tbquant-strategy-builder` target CN futures on a specific
runtime; `signal-to-strategy` bridges a signal JSON into ssquant; `strategy-lab` uses the
ssquant MCP. This skill is **framework-neutral, overseas-facing, with an offline stdlib+pandas
backtest** — the deliverable is a standalone research script, not a live trading system.

## 🚀 Quick Start

```bash
cp -r skill-global-macro-trend-strategy ~/.claude/skills/global-macro-trend-strategy
```

A self-contained demo (synthetic random-walk prices + built-in MA signal) runs with no data file:

```bash
python skill-global-macro-trend-strategy/scripts/backtest.py --demo --zscore --enter 0.5 --exit 0.2
```

Real run (your own price CSV + signal CSV):

```bash
python scripts/backtest.py --prices CL=F.csv --signal my_signal.csv --sizing vol_target --fee-bps 2 --slip-bps 1
```

Example trigger prompts:

```text
Build a trend-following research backtest on crude (CL=F) from a term-structure signal, vol-target sizing, report CAGR/Sharpe/drawdown
Turn this macro score series into a framework-neutral backtestable strategy with a stop and a drawdown guard, research only, no orders
```

## 🗃 Data Sources & Dependencies

- **Public overseas daily prices**: Yahoo Finance / stooq continuous futures (`CL=F`, `GC=F`,
  `ES=F`), FX (`EURUSD=X`), indices; the user downloads CSVs and is responsible for licensing.
- **Signal**: sibling overseas skills / user-supplied `date,value` / built-in MA demo.
- **Pandadata (optional)**: if the signal comes from a Pandadata overseas interface, do **not**
  invent method names — delegate the actual calls to the `pandadata-api` skill.
- **Dependency**: Python 3 + pandas (missing pandas → clear install hint, non-zero exit).

## ⚠️ Limits & Risk Boundary

- **Research backtest only**: no live orders, no broker, no live data.
- **Look-ahead avoidance**: signal at `t`, trade at `t+1`; the script enforces `shift(1)`.
- **Known limits**: continuous-contract roll and survivorship bias can overstate returns;
  in-sample overfit risk; costs dominate at high turnover; single/few-symbol results have limited
  statistical meaning. **Results are illustrative, not predictive.**
- **Human confirmation**: any trading decision is the user's own; external writes/orders are out of scope.
