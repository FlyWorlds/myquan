# 贡献说明

感谢对本项目的改进。提交前请确保修改保持 BUILD 的可复用性、点时性和研究边界。

## 提交原则

- 保持正式入口 `scripts.build.run(input_data, config=None)` 与 `validate_input` 的兼容性。
- 真实数据仅使用 Panda Data 或调用方提供的结构化数据；不得用当前成分股倒推历史指数池。
- 将硬门槛与软评分对照明确区分；银行毛利率必须保持 `N/A`，不得填充中性分。
- 不生成订单，不加入收益保证或个性化投资建议。
- 新增或修改组合规则时，应提供点时回测证据，并说明样本范围、交易成本和局限性。

## 本地验证

```powershell
pip install -r requirements.txt
python scripts/test.py
python scripts/demo.py
```

请确认离线演示能够生成 JSON 与 HTML，且默认模式不调用网络。

## 数据与凭证

- 严禁提交 Panda Data 账号、密码、访问令牌、Cookie、私钥或本地 `.env` 文件。
- 不提交 `output/`、缓存、浏览器自动化状态、`__pycache__/` 或测试临时产物。
- 若发现敏感信息已进入提交历史，请停止传播并通过私有渠道联系维护者处理。

## 文档与提交信息

- 面向使用者的说明使用中文，代码标识符和接口字段沿用现有英文命名。
- 更新输入、输出、数据口径或研究边界时，同步更新 `README.md` 与 `SKILL.md`。
- 提交信息使用简洁动词短语，例如：`新增年度持仓演示`、`修正点时成分口径`。
