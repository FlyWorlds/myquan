# 凯恩斯长期预期与反共识投资

> QuantSkills 社区项目，由 GitHub 用户 `cikeqi` 维护。项目尚未经过独立审核，不代表 QuantSkills 官方认证，也不承诺收益或生产环境适用性。

## 定位

本 Skill 将凯恩斯《通论》第十二章的长期预期、不确定性、信心、动物精神、市场惯例与选美机制，连接到格雷厄姆的安全边际和霍华德·马克斯的第二层思维，形成可追溯的研究报告。

它不是：

- 机械低 PE 选股器；
- 单纯超跌抄底器；
- 把跌幅当作低估的工具；
- 收益预测或自动买卖指令。

## 核心问题

对每个标的回答：

1. 企业在正常状态下能产生多少长期收益？
2. 当前价格隐含了怎样的增长、利润率和资本回报要求？
3. 市场共识是否过度乐观或过度悲观？（PandaData 无正式一致预期时只能使用“共识代理”）
4. 低估是否可能只是基本面持续恶化？
5. 有什么催化剂可以检验判断？什么条件会证伪判断？

## 数据与边界

- 严格使用 PandaData；不把网页、新闻、手工行情或第三方数据混入量化结论。
- 凭证只从 `PANDA_USERNAME`/`PANDA_PASSWORD` 或 `~/.pandadata/pandadata.env` 读取，禁止硬编码。
- 所有结果带 `as_of` 和 provenance；禁止使用分析日之后才公开的信息。
- 区分事实、衍生指标、代理和判断。
- `empty/error/unsupported` 不填零、不当作中性；评分按可用权重归一化并报告覆盖率。
- A股估值因子通过 `get_factor` 获取，核心字段包括 `pe_ratio_ttm`、`pb_ratio_lf`、`pb_ratio_ttm` 和 `market_cap`；SDK 中的 `get_stock_mktfin_indicator` 是港股 reader，不用于 A 股。
- `get_fina_forecast` 是公司业绩预告，不等同于卖方一致预期。
- 北向持仓通常是滞后快照；ETF 净申赎是资金偏好代理；成交额不是主力净流入。

## 评分与门控

| 维度 | 权重 |
|---|---:|
| 长期预期差 | 25% |
| 基本面耐久性 | 30% |
| 估值安全边际 | 20% |
| 市场共识与定位代理 | 15% |
| 催化剂与证伪清晰度 | 10% |

“便宜但恶化”优先于总分：盈利与现金流同步恶化、非标准审计等会触发否决；高分也可能为 `CAUTION` 或 `FAIL`。

## 可以怎样提问

以下问题是通用模板。将 `[股票名称/代码]`、`[股票A]`、`[股票B]` 或 `[股票池]` 替换为实际对象即可。

### 1. 单股完整分析

```text
用凯恩斯反共识 Skill 分析[股票名称/代码]。判断企业性投资逻辑是否成立、市场预期是否过度乐观或悲观、当前价格是否具有安全边际，并给出研究门控、催化剂、反证和证伪条件。
```

```text
用凯恩斯反共识 Skill 分析[股票名称/代码]。重点告诉我：它是便宜还是价值陷阱，现在是预期错位的研究/介入时点，还是应该继续等待？
```

### 2. 预期状态与介入时点

```text
[股票名称/代码]基本面看起来有改善迹象，但现在是不是合适的介入时点？请从长期预期、市场信心、流动性、估值和预期修复条件分析，不要预测短线涨跌。
```

```text
判断[股票名称/代码]当前处于过度悲观、预期修复、合理定价还是乐观透支阶段，并说明判断依据。
```

```text
如果现在还不是较好的时点，需要等哪些条件出现？请区分企业改善信号、市场预期修复信号和纯价格信号。
```

### 3. 价值陷阱排查

```text
[股票名称/代码]的估值已经下降，请检查这是市场过度悲观还是价值陷阱。重点分析收入、净利润、经营现金流、资产负债、库存周期、行业竞争和审计风险，并区分周期性问题与永久性问题。
```

```text
这只股票很便宜，但会不会是“便宜但恶化”？请列出硬否决条件、降级条件和需要观察的改善指标。
```

### 4. 过度乐观与预期透支

```text
分析[股票名称/代码]当前是否存在预期透支。公司即使继续增长，当前价格是否已经反映了过高的收入增速、利润率或行业景气假设？请列出最脆弱的三个市场预期。
```

```text
这是一家好公司，但现在是不是一只好股票？请分别评价企业质量、估值安全边际和市场共识拥挤度。
```

### 5. 过度悲观与反共识机会

```text
判断市场是否对[股票名称/代码]过度悲观。不要把股价下跌本身作为理由，请同时检查估值、收入利润、现金流、资产负债、行业周期和经营改善证据。
```

```text
寻找市场预期很低、但现实基本面开始改善的股票，并列出改善证据、后续验证节点和证伪条件。
```

### 6. 催化剂与证伪条件

```text
为[股票名称/代码]建立反共识投资跟踪表。列出未来两个季度最重要的基本面指标、市场预期修复信号、已知催化剂和可量化证伪条件。
```

```text
什么数据改善才说明[股票名称/代码]的长期预期开始修复？什么情况说明原来的投资逻辑已经失败？
```

### 7. 多股比较

```text
使用凯恩斯反共识 Skill 比较[股票A]、[股票B]和[股票C]。分别评价企业性投资、基本面耐久性、市场预期代理、估值安全边际、催化剂和证伪条件，并区分“最好的公司”和“当前赔率最好的股票”。
```

```text
比较[股票A]与[股票B]：谁是质量更好的公司，谁是价格更好的投资，谁最可能是价值陷阱？不要只按 PE 排序。
```

### 8. 持仓组合体检

```text
对以下持仓做凯恩斯式预期状态体检：[持仓A]、[持仓B]、[持仓C]。输出每只股票的 PASS/CAUTION/FAIL、基本面耐久性、市场预期状态、安全边际、催化剂和证伪条件。
```

```text
找出我持仓中最依赖市场乐观情绪的股票、最可能被过度悲观定价的股票，以及基本面已经证伪的股票。
```

### 9. 批量寻找候选

```text
从[沪深300/中证500/中证1000/自定义股票池]中寻找市场预期较低、但基本面没有同步恶化的公司。不要只按 PE 排序，必须检查现金流、资产负债、估值安全边际、催化剂和价值陷阱风险。
```

```text
从[股票池]中筛选“收入降幅收窄 + 经营现金流改善 + 估值偏低”的反共识候选，并单独列出低估值但基本面恶化的价值陷阱。
```

### 10. 历史时点复盘

```text
以[分析截止日]为分析截止日，只使用当时已经披露的数据，用凯恩斯反共识 Skill 分析[股票名称/代码]，不得读取未来财务报告。列出当时可形成的判断、无法知道的信息和后续证伪条件。
```

```text
只使用[历史日期]以前公开的数据，复盘某次大跌是否构成反共识机会，并区分当时的信息与事后才知道的结果。
```

### 11. 直接生成投资决策卡

```text
用凯恩斯反共识 Skill 给[股票名称/代码]生成一张投资决策卡，包含：企业性投资是否成立、市场预期状态、价格隐含预期、安全边际、价值陷阱否决门、催化剂、反证、证伪条件、PASS/CAUTION/FAIL，以及当前更适合研究、分批观察、等待还是回避。
```

## 适合与不适合的问题

适合：

- “它是便宜还是价值陷阱？”
- “市场是否过度悲观？”
- “好公司是否已经被过度定价？”
- “现在是预期错位的介入时点吗？”
- “哪些数据会证明我判断错了？”
- “谁是最好的公司，谁是当前赔率最好的股票？”

不适合：

- “明天会不会涨停？”
- “下周最高价是多少？”
- “哪个价格一定是底？”
- “给我一只稳赚的股票。”
- “什么时候一定翻倍？”

请将短线问题改写为：

> 当前预期是否已经极端？基本面是否支持分批研究？安全边际是否足够？继续下跌时哪些条件必须成立？

## 结论等级

- **PASS：**值得进入进一步研究或分批观察，不等于自动买入；
- **CAUTION：**逻辑有部分支持，但估值、催化剂或数据覆盖不足；
- **FAIL：**存在硬否决或企业性投资逻辑已明显破坏；
- **N/A：**关键数据不足，不能形成可靠判断。
