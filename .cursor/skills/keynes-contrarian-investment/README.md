# 凯恩斯长期预期与反共识投资 Skill

简体中文 | [English](README.en.md)

> QuantSkills 社区项目，由 GitHub 用户 `cikeqi` 维护。项目尚未经过独立审核，不代表 QuantSkills 官方认证，也不承诺收益或生产环境适用性。

这是一个“基本面选股 + 市场预期判断 + 预期状态择时 + 价值陷阱排查”工具。它不预测明天的涨跌，而是帮助判断一家公司是否值得研究、当前预期是否过高或过低，以及什么情况会证明原来的判断错误。

## 快速开始

```bash
python3.11 scripts/expectation_contrarian.py \
  --symbol 600519.SH \
  --out-json /tmp/keynes_600519.json \
  --out-md /tmp/keynes_600519.md
```

批量使用指数股票池：

```bash
python3.11 scripts/expectation_contrarian.py --universe csi300 --top-n 20
```

先探测当前 PandaData 账号的接口和字段：

```bash
python3.11 scripts/expectation_contrarian.py --symbols 600519.SH --probe-only
```

凭证配置：环境变量优先，也可配置 `~/.pandadata/pandadata.env`：

```text
PANDA_USERNAME=...
PANDA_PASSWORD=...
```

## 研究逻辑

长期预期不是精确预测；市场共识在没有正式一致预期字段时只能用历史估值、公司业绩预告和市场行为做代理。Skill 首先判断企业性投资的基本面耐久性，然后分析价格隐含预期和安全边际，最后考察市场定位、催化剂与证伪条件。

低估值但盈利与现金流同步恶化的标的不会因为“便宜”自动入选。

## 可以问什么

将下面模板中的 `[股票名称/代码]`、`[股票A]`、`[股票B]` 或 `[股票池]` 替换为实际对象即可。

### 单股完整分析

```text
用凯恩斯反共识 Skill 分析[股票名称/代码]。判断企业性投资逻辑是否成立、市场预期是否过度乐观或悲观、当前价格是否具有安全边际，并给出研究门控、催化剂、反证和证伪条件。
```

### 判断是否值得进一步研究

```text
[股票名称/代码]现在是便宜，还是基本面正在恶化？请判断当前更适合进一步研究、分批观察、等待还是回避，并说明支持证据和证伪条件。
```

### 判断介入时点

```text
[股票名称/代码]基本面看起来有改善迹象，但现在是不是合适的介入时点？请从长期预期、市场信心、流动性、估值和预期修复条件分析，不要预测短线涨跌。
```

### 排查价值陷阱

```text
[股票名称/代码]的估值已经下降，请检查这是市场过度悲观还是价值陷阱。重点分析收入、净利润、经营现金流、资产负债、库存周期、行业竞争和审计风险，并区分周期性问题与永久性问题。
```

### 检查预期透支

```text
分析[股票名称/代码]当前是否存在预期透支。当前价格是否已经反映了过高的收入增速、利润率或行业景气假设？请列出最脆弱的三个市场预期。
```

### 寻找过度悲观机会

```text
判断市场是否对[股票名称/代码]过度悲观。不要把股价下跌本身作为理由，请同时检查估值、收入利润、现金流、资产负债、行业周期和经营改善证据。
```

### 建立催化剂和证伪条件

```text
为[股票名称/代码]建立反共识投资跟踪表。列出未来两个季度最重要的基本面指标、市场预期修复信号、已知催化剂和可量化证伪条件。
```

### 比较多只股票

```text
使用凯恩斯反共识 Skill 比较[股票A]、[股票B]和[股票C]。分别评价企业性投资、基本面耐久性、市场预期代理、估值安全边际、催化剂和证伪条件，并区分“最好的公司”和“当前赔率最好的股票”。
```

### 持仓组合体检

```text
对以下持仓做凯恩斯式预期状态体检：[持仓A]、[持仓B]、[持仓C]。输出每只股票的 PASS/CAUTION/FAIL、基本面耐久性、市场预期状态、安全边际、催化剂和证伪条件。
```

### 批量寻找候选

```text
从[沪深300/中证500/中证1000/自定义股票池]中寻找市场预期较低、但基本面没有同步恶化的公司。不要只按 PE 排序，必须检查现金流、资产负债、估值安全边际、催化剂和价值陷阱风险。
```

### 历史时点复盘

```text
以[分析截止日]为截止日，只使用当时已经披露的数据，用凯恩斯反共识 Skill 分析[股票名称/代码]，不得读取未来财务报告。列出当时能够形成的判断、无法知道的信息和后续证伪条件。
```

### 生成投资决策卡

```text
用凯恩斯反共识 Skill 给[股票名称/代码]生成一张投资决策卡，包含企业性投资是否成立、市场预期状态、价格隐含预期、安全边际、价值陷阱否决门、催化剂、反证、证伪条件、PASS/CAUTION/FAIL，以及当前更适合研究、分批观察、等待还是回避。
```

### 不适合的问题

本 Skill 不适合回答：

- 明天会不会涨停；
- 下周最高价是多少；
- 哪个价格一定是底；
- 什么时候一定翻倍；
- 直接给出稳赚的股票或自动买卖指令。

可以把短线问题改写为：

> 当前预期是否已经极端？基本面是否支持进一步研究？当前价格是否具有安全边际？哪些条件会证明这个判断错误？

## 输出

- JSON：指标、公式、状态、日期、评分、否决门、代理限制和 provenance；
- Markdown：中文研究报告；
- N/A：接口空、错误或不支持时保留章节并显示原因。

运行测试：

```bash
python3.11 -m pytest tests -q
```

## 数据来源、假设与限制

- 数据来源：仅使用 PandaData；具体接口、字段和数据边界见 `references/`。
- 关键假设：在缺少正式一致预期数据时，使用历史估值、业绩预告和市场行为作为共识代理。
- 已知限制：代理指标可能滞后或失真；缺失和不支持的数据保持为 N/A，不填零。
- 风险边界：输出仅供研究与教育，不构成投资建议、收益承诺或自动交易指令。
