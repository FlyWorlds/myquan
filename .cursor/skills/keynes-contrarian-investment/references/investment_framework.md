# 理论框架

## 凯恩斯

《通论》第十二章的核心不是精确预测，而是长期投资在根本不确定性下如何仍然发生。

- 长期预期：估计资产在整个生命周期内的未来收益。
- 信心：对预测可靠性的判断，影响投资规模。
- 动物精神：在概率无法可靠计算时，促使人行动而不是不行动的自发冲动。
- 市场惯例：在缺乏更好信息时，暂时假设现状延续。
- 选美机制：专业投资者可能从估计企业收益转向预测其他投资者的预期。
- 企业性投资：研究长期生产性收益。
- 投机性预测：研究市场价格和心理的变化。

## 格雷厄姆与马克斯

格雷厄姆的安全边际要求为估计误差留出缓冲；马克斯的第二层思维要求先识别共识，再判断共识已经反映多少、哪个假设最脆弱。

反共识不等于机械地与大众相反。正确问题是：市场的悲观/乐观是否超过了企业长期收益的现实变化？

## 工程化原则

1. 事实、衍生指标、代理和判断分开。
2. 价格下跌不是低估的充分条件。
3. 低估值但盈利/现金流持续恶化，优先判定为价值陷阱风险。
4. 每一个研究结论都要有催化剂、反证和证伪条件。
5. 不确定性高时，降低仓位和结论强度，而不是伪造精确度。
