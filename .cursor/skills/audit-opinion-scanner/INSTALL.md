# Multi-Platform Install Guide

This package contains 1 QuantSkills skill directory:

- `skill-audit-opinion-scanner` (this repository): Multi-dimensional financial analysis system covering audit opinion scanning, 25-item financial caching, 15-ratio computation, industry benchmarking, 5-dimension rapid scoring, 8-section deep analysis, **⭐ XGBoost audit risk ex-ante prediction**, and composite risk detection.

---

## Claude Code

Copy this entire repository directory to your Claude Code skills folder:

```bash
# macOS / Linux
cp -R skill-audit-opinion-scanner ~/.claude/skills/
```

```powershell
# Windows (PowerShell)
New-Item -ItemType Directory -Force "$HOME\.claude\skills"
Copy-Item ".\" "$HOME\.claude\skills\skill-audit-opinion-scanner" -Recurse -Force
```

After installation, invoke in Claude Code:

```
/skill-audit-opinion-scanner
```

Requirements: Python 3.10+, pandas >= 2.0, xgboost >= 2.0, scikit-learn >= 1.3, pytest >= 7.0 (for tests only).

## Standalone (Any Python 3.10+ Runtime)

```bash
pip install -r requirements.txt

# Build local cache (requires panda_data credentials, one-time, ~36s for CSI1000)
export PANDA_DATA_USERNAME="your_username"
export PANDA_DATA_PASSWORD="your_password"
python scripts/build_cache.py --universe 000852.SH --quarters 20

# Scan audit opinions (requires credentials)
python scripts/scan.py --start-quarter 2020q4 --end-quarter 2026q2

# ⭐ Train ML audit prediction model (requires cache built)
python scripts/predict.py --train --backtest

# Now all analysis + prediction scripts work offline
python scripts/analyze_stock.py 600519.SH
python scripts/analyze_quick.py --all
python scripts/predict.py --predict
python scripts/predict.py --stock 600267.SH
```

## Data Products (Agent Consumption)

Other agents or strategies can consume the cached data and ML predictions directly without running any scripts:

```python
from pathlib import Path
import pandas as pd

skill_root = Path(__file__).resolve().parent.parent

# Financial data (25 items + 15 ratios × 20 quarters × 1300 stocks)
df = pd.read_parquet(skill_root / "data" / "fina_cache.parquet")

# Industry classification (5,514 stocks × 31 L1 industries)
indu = pd.read_parquet(skill_root / "data" / "fina_industry.parquet")

# Audit risk blacklist (generated by scan.py)
audit = pd.read_csv(skill_root / "output" / "audit_risk_2025q4.csv")
bad_stocks = audit[audit["risk_level"] >= 2]["symbol"].tolist()

# ⭐ ML audit risk predictions (generated by predict.py)
pred = pd.read_csv(skill_root / "output" / "audit_predictions_2026q2.csv")
high_risk = pred[pred["prob_nonstandard"] >= 0.3]
```

## Usage Boundaries (All Platforms)

- **Research & educational use only** — not investment advice.
- Data sourced from panda_data; always verify against official filings.
- Cache building and audit scanning require panda_data credentials (PANDA_DATA_USERNAME / PANDA_DATA_PASSWORD).
- All analysis + prediction scripts work offline once cache is built.
- Current default coverage: CSI1000 (1,300 stocks). Expandable via `--universe`.
- ML model has 53 positive training samples; AUC 0.788 is valid but moderate. Combine with rule-based screening.
- See `SKILL.md` for full limitations and `README.md` / `README.en.md` for project overview.
