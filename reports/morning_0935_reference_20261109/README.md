# 9:35 早盘止损基准研究

本次仅分析，未改生产交易规则。运行：`.venv/bin/python reports/morning_0935_reference_20261109/analyze.py`。

样本：2026-10-27 至 2026-11-05，8 个交易日，两个历史缓存股票池合并去重后 55 只股票、440 个股票日。所需 09:31—10:00 和 15:00 时间点均齐全，重叠池数据无冲突。原始文件及 SHA256 见 sources.json。

这是隔离单条规则的情景分析，不是真实持仓或完整策略回测。每个股票日假设已有等额可卖仓位，一分钟收盘价作为观察和成交代理，未触发者分别按 10:00 估值、或假设继续持有至 15:00。没有模拟其他止盈止损、费用、滑点、跌停卖出限制、买入和再入场。因此差值不能当成账户收益或可实现收益。分钟内毛刺不可见。当前股票池回看历史有选择偏差，样本短且股票日相互关联。

| 规则 | 触发股票日 | 10点估值的平均差值，相对原规则 | 持有到收盘情景的平均差值 |
|---|---:|---:|---:|
| 原开盘价 -1%，9:30起 | 203 | 0 | 0 |

| 9:35收盘价 -1%，收线后起 | 180 | -0.0225个百分点 | +0.1899个百分点 |

均值分母为全部440股票日；以当日开盘价归一化，不是复利组合收益。9:35新基准用09:31—09:35五个完整一分钟柱的最后收盘价；首次可观察的后续一分钟为09:36。止损阈值按分向下取整，10:00起不触发。本研究09:30竞价快照close作为开盘代理，缺失时取09:31柱open，避免缓存竞价open=0的问题。

原规则9:35前触发131次，其中76次在9:35价格已高于卖出价，84次在10:00高于卖出价。换基准避免原触发77次，同时新增54次，因此净减少23次，不能将77次全部称为优化。

风险实例：002929在2026-11-04开盘51.00，9:35收47.94；原规则观察卖出49.87，新规则观察卖出47.34，多损失相当于开盘价4.96个百分点。另一方向，前五分钟上涨会抬高基准，导致原规则不卖而新规则卖出，可能错失后续反弹。

结论：用户的毛刺担忧有样本支持，但直接替换基准尚不能证明更优。先评估只延迟起算时间更容易隔离效果；若继续测试9:35基准，需要保留独立成本硬止损，并在完整策略里对照其他退出规则与实际持仓。当前quote_exit.py中常规退出判定与附加早盘规则并存，不能假定关闭此规则就不会在9:35前退出。历史部分脚本只对低开保护持仓启用新止损，与当前全局规则口径不同，未用于本次数值结论。

校验：股票日唯一性、触发价与阈值、10点边界、9:35基准不得提前使用、价差独立重算均通过。详细逐笔见stock_days.csv，按日敏感性见daily_deltas.csv。
