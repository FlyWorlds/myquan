# 首根五分钟最低价触发：止损线成交与9:35收盘成交对照

按用户本轮指定口径重算，不使用前次的一分钟收盘触发口径。未修改生产规则。

- 样本：2026-10-27—2026-11-05，8个交易日、55只股票、440个股票日，来自前次研究两个历史缓存池，重叠股票日去重。
- 五分钟柱：09:31—09:35五根完整一分钟柱合成；最低价取五根low最小值，收盘取09:35 close。
- 触发条件：最低价严格小于开盘价×99%。开盘代理沿用09:30竞价close，缺失时用09:31 open。
- A组：触发即假设按开盘价×99%精确成交。B组：完全相同的触发样本，等9:35按收盘价成交。不触发的股票日不纳入主比较。
- 差值：(B卖价−A卖价)/开盘价×100，单位为百分点；假设各股票日开盘名义本金相同。

205个触发股票日：A平均相对开盘−1.0000%，B平均−0.9582%，B平均改善0.0418个百分点；116次B更好（56.59%），88次更差，1次相同；中位改善0.1678个百分点。最大改善4.8549个百分点，最大恶化6.8824个百分点。不是相对持仓成本的交易盈亏，也不是账户累计收益。

逐日平均差值：10-27 +1.6987；10-28 −0.6101；10-29 +0.2328；10-30 +0.8058；11-02 −0.8952；11-03 +0.1907；11-04 +0.1018；11-05 +0.1763（百分点）。

最差实例：002009，11-02，开盘17.00，止损价16.83，五分钟最低15.51，9:35收15.66，等待多损失6.8824个百分点。最好实例：002088，11-04，开盘8.82，理论止损价8.7318，9:35收9.16，等待改善4.8549个百分点。

敏感性：若只算时间标签严格早于09:35的分钟low（09:31—09:34），197次触发，平均改善0.0434个百分点；因缺少tick，无法将09:35这一分钟内部再拆分。若阈值按现有代码向下取整到分，且仍要求最低价严格低于该阈值，触发样本191次，等待平均差值变为−0.0297个百分点。该敏感性同时改变触发集合和成交价；不可将它解释为单独成交价取整的影响。

结论：按用户精确99%理论成交假设，等待收盘在本样本略好，但均值接近零且对报价取整敏感，不能证明稳定优势。少数持续大跌抵消了多数反弹改善。

边界：这是单条规则的配对价格回测，不是实际持仓或完整策略回测。没有模拟T+1、跌停无法卖出、其他止损、费用、滑点和再入场。低点穿越阈值并不证明真实订单一定能按阈值成交，99%精确价格还可能不符合分价位；9:35收盘价同样为理想成交代理。样本仅8天且沿用历史冻结池，有选择偏差和股票日相关性。

复现：`.venv/bin/python reports/first5m_stop_vs_close_20261109/analyze.py`。
数据：all_stock_days.csv含全部样本，triggered_cases.csv含205个触发样本，daily.csv为按日汇总，sources.json保存源文件哈希。校验了源文件哈希、股票日唯一性、首五分钟完整性与OHLC约束、相同触发集合、收益差独立重算和计数加总。
