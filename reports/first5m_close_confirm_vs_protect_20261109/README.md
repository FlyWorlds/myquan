# 9:35收盘确认与首五分钟盘中保护

本轮更正了对照逻辑：A只在09:35收盘价低于开盘价×99%时卖；B在首五分钟最低价低于开盘价×99%时，假设按该止损线卖。A未触发时继续持有，而不是上一轮对所有盘中触发样本都在09:35卖出。

范围：2026-10-27至2026-11-05，55只股票、8个交易日、440个股票日，去重合并前两次历史池缓存。输入为前次已核验的all_stock_days.csv与stock_days.csv，按symbol/day一对一连接；可追溯来源及哈希见../first5m_stop_vs_close_20261109/sources.json。五分钟柱由09:31—09:35的完整一分钟柱合成；开盘代理使用09:30竞价close，缺失时用09:31 open。

主结果：A卖88次，B卖205次；A少卖117次。235个股票日两者均不卖。所有股票日假设同等开盘名义本金，比较相对开盘价格的收益；不代表真实账户或持仓成本盈亏。

| 估值终点 | A平均收益 | B平均收益 | A−B |
|---|---:|---:|---:|
| 09:35 | +0.1581% | +0.1386% | +0.0195个百分点 |
| 10:00 | +0.4093% | +0.3239% | +0.0854个百分点 |
| 15:00 | +0.3301% | +0.1537% | +0.1764个百分点 |

两组卖出后持现金；未卖出的直接持有到各估值终点，不追加09:35以后的开盘-1%止损、其他止盈止损或再入场。三个终点是独立情景，不能相加。

机制分解：
- 88个两者都卖的样本：A平均较开盘−2.4514%，B理论−1%，等待平均多损失1.4514个百分点。
- 117个盘中跌破但09:35收回或等于止损线的样本：A保留仓位；到10:00有87次好于B、30次差于B；到15:00有71次好于B、46次差于B。
- 全440个股票日：10:00时A较好87次、较差118次、相同235次；15:00时较好71次、较差134次、相同235次。均值优势来自幅度，不能误称为整体胜率更高。

稳定性：10点和15点终点均只有4/8天A均值较好。收盘差值在11-04为+2.0238个百分点，去掉这一天，其余7天平均约−0.0875个百分点。按分向下取整并仍采用严格低于时，A卖86次、B卖191次；10点差值+0.0453个百分点，收盘+0.1687个百分点。取整敏感性同时改变触发集合及成交价。

结论：该短样本中A平均收益略高且减少卖出，但下跌保护明显弱于B，全天优势集中于单日，不能证明稳定更优。若目标是减少早盘毛刺，A更符合目标；若目标是把前五分钟下跌尽早截断，B更符合目标。未修改生产规则。

限制：按用户口径假设B准确成交在开盘价99%，可能存在非合法分价位和跳价/滑点；A也假设可成交在已完成的09:35收盘价。没有费用、跌停流动性、T+1、真实持仓、其他退出规则和资金约束。短期冻结池存在选择偏差、股票日相关性。本研究是单条规则情景回测，不是完整策略回测。
